# 아침 과제 5 · 무료 Gemini API 키를 발급받아 보관하기

10월 6일 (화) · 아침 과제

**오늘 하는 일:** 구글 Gemini API 키를 **무료로 발급받고**, `.env` 파일에 보관하고, 키가 살아 있는지 `curl` 명령어로 확인합니다.

오늘 2교시부터 이 키로 LLM 을 호출합니다. **키가 없으면 오늘 실습을 할 수 없습니다.**

키를 만든 뒤에는 **깃허브에 올라가지 않게 막습니다.**


---

## 1. 왜 이걸 하는지 찾아봅니다

먼저 **왜 API 키가 필요한지**, 그리고 **왜 깃배시를 쓰는지**를 직접 찾아보고 한두 줄씩 적습니다.

| 질문 | 검색어 예시 |
|---|---|
| LLM 을 API 로 부를 때 왜 키를 요구할까요? | `API 키 란`, `LLM API 키 왜 필요`, `API 키 유출 사고` |
| 보안 담당자가 다루는 서버는 어떤 운영체제를 가장 많이 쓸까요? 윈도우 PC 에서 PowerShell 대신 깃배시를 쓰면 무엇이 좋을까요? | `서버 운영체제 점유율`, `bash 란`, `git bash powershell 차이` |

정답을 맞히는 과제가 아닙니다. **찾은 내용을 자기 말로 적는 것**이 과제입니다.

---

## 2. 이 말들이 무슨 뜻인지 찾아봅니다

검색해서 읽고 자기 말로 한 줄씩 적습니다.

| 찾아볼 말 | 무엇을 알아 오면 되나 (힌트) |
|---|---|
| LLM (엘엘엠) | 무엇을 입력받아 무엇을 내놓는 프로그램인가 |
| 무료 등급 (free tier) | 무료로 쓸 때 무엇에 제한이 걸리는가 |

오른쪽은 **힌트일 뿐입니다.** 뜻은 직접 찾아서 자기 말로 적습니다.

## 3. VS Code 터미널이 Git Bash 인지 확인합니다

10/2 아침 과제에서 터미널을 Git Bash 로 바꿨습니다. 오늘은 확인만 합니다.

1. VS Code 위 메뉴에서 **Terminal › New Terminal**(터미널 › 새 터미널) 을 누릅니다.
2. 첫 줄에 `MINGW64` 가 보이면 됩니다.

`PS C:\Users\이름>` 으로 시작하면 아직 PowerShell 입니다. `Ctrl+Shift+P` → `Select Default Profile` → **Git Bash** 를 고르고 터미널을 다시 엽니다.

## 4. 키를 발급받습니다

**개인 gmail 계정으로 로그인합니다.** 학교·회사 계정은 관리자가 막아 둔 경우가 있습니다.

1. 브라우저에서 `https://aistudio.google.com` 에 들어갑니다.
2. 개인 gmail 계정으로 로그인하고, 약관에 동의합니다.
3. 화면에서 **Get API key** 를 누릅니다.
4. 키가 이미 하나 만들어져 있으면 그것을 씁니다. 없으면 **Create API key** 를 누릅니다.
5. 키를 **복사**합니다. 영문자와 숫자가 섞인 긴 글자입니다.

카드 번호나 결제 정보는 넣지 않습니다. 결제를 요구하는 화면이 나오면 **닫고 강사를 부릅니다.**

### 접속할 수 없다는 화면이 나오면

- 구글 계정에 **생년월일이 등록되어 있는지** 확인합니다. (`https://myaccount.google.com` → 개인 정보)
- 그래도 안 되면 강사를 부릅니다.

## 5. 키를 `.env` 파일에 보관합니다

키는 **비밀번호와 같습니다.** 9/30 에 배운 대로 코드가 아니라 `.env` 파일에 둡니다.

1. VS Code 에서 `security-agent-toolkit` 폴더를 엽니다.
2. **File › New File**(파일 › 새 파일) 을 누르고 아래 한 줄을 적습니다. 등호 앞뒤에 빈칸을 넣지 않습니다.

   ```
   GEMINI_API_KEY=여기에_복사한_키를_붙여넣습니다
   ```

3. **File › Save**(파일 › 저장) 을 누르고 `security-agent-toolkit` 폴더에 `.env` 라는 이름으로 저장합니다.
   이름이 점(`.`)으로 시작하고 뒤에 `.txt` 가 붙지 않습니다.

터미널에서 확인합니다. VS Code 왼쪽 파일 목록의 빈 곳을 오른쪽 클릭하고 **Open in Integrated Terminal** 을 누르면 터미널이 `security-agent-toolkit` 폴더에서 열립니다.

```
$ pwd
$ ls -a
```

`pwd` 의 결과가 `…/security-agent-toolkit` 으로 끝나는지 봅니다.

목록에 `.env` 가 보이면 됩니다.

## 6. ⚠ 중요 — .gitignore는 키가 깃허브에 올라가지 않게 막습니다 

**이 단계를 건너뛰지 않습니다.** `.env` 는 깃허브에 올릴 폴더 안에 있습니다. 이대로 폴더를 통째로 깃허브에 올리면 이 파일도 함께 올라갑니다.

깃허브에 한 번 올라간 키는 **파일을 지워도 기록에 남습니다.** 그래서 올리기 전에 먼저 막아 둡니다.

1. VS Code 에서 **File › New File**(파일 › 새 파일) 을 누르고 아래 한 줄만 적습니다.

   ```
   .env
   ```

2. **File › Save**(파일 › 저장) 을 누르고 `security-agent-toolkit` 폴더에 `.gitignore` 라는 이름으로 저장합니다.
   이것도 이름이 점(`.`)으로 시작하고 뒤에 `.txt` 가 붙지 않습니다.
3. 터미널에서 확인합니다.

```
$ ls -a
```

목록에 `.env` 와 `.gitignore` 가 **둘 다** 보이면 됩니다.

이 파일이 왜 `.env` 를 막아 주는지는 10/7 에 배웁니다. 오늘은 **키를 만들면 이 파일부터 만든다**는 것만 기억합니다.

### 키를 다룰 때 지킬 것 세 가지

- 단톡방·메신저에 키를 올리지 않습니다.
- 화면을 공유할 때 `.env` 를 열어 두지 않습니다.
- 깃허브에 웹으로 파일을 올릴 때 `.env` 를 끌어다 놓지 않습니다. `.gitignore` 는 웹 업로드를 막아 주지 않습니다.

실수로 키를 올렸다면 **바로 강사를 부릅니다.** 그 키는 지우고 새로 발급받아야 합니다.

## 7. 키가 살아 있는지 확인합니다

10/2 에 배운 `curl` 과 `-H` 를 씁니다. 파이썬은 쓰지 않습니다.

아래 주소는 **쓸 수 있는 모델 목록**을 돌려줍니다. 키는 `x-goog-api-key` 라는 헤더에 싣습니다.

```
$ curl -H "x-goog-api-key: 여기에_내_키" "https://generativelanguage.googleapis.com/v1beta/models"
```

| # | 하고 싶은 일 | 나오면 성공 |
|---|---|---|
| ① | **내 키**를 싣고 요청한다 | `"models"` 로 시작하는 긴 목록이 나온다 |
| ② | 키의 **마지막 글자를 하나 지우고** 요청한다 | `UNAUTHENTICATED` 가 나온다 |
| ③ | **헤더를 빼고** 주소만 요청한다 | `PERMISSION_DENIED` 가 나온다 |

②와 ③은 명령을 직접 고쳐서 칩니다. 둘이 **서로 다른 메시지**를 돌려주는 이유를 생각해 보세요.

> 💡 **이전 명령 다시 불러오기** — ②와 ③은 처음부터 다시 치지 않습니다.
> - 터미널에서 **↑(위 화살표)** 를 누르면 방금 입력한 명령이 다시 나옵니다. 여러 번 누르면 더 이전 명령이 나옵니다. **↓** 는 최근 쪽으로 돌아옵니다.
> - 불러온 명령에서 **←→ 로 커서를 옮겨** 고칠 부분만 고친 뒤 Enter 를 누릅니다.
> - 터미널에서만 됩니다. 노트북 셀 안에서 ↑↓ 는 줄 사이를 움직이는 키입니다.

같은 요청을 여러 번 반복하지 않습니다. 무료 등급은 하루에 부를 수 있는 횟수가 정해져 있습니다.

## ⚠ 중요 — 무료 키는 1분에 15번까지만 호출할 수 있습니다

- 무료 Gemini API 키의 한도는 **1분에 15번**입니다.
- 한도를 넘으면 상태 코드 **`429`** 가 반환됩니다. 키가 고장 난 것이 아닙니다.
- `429` 가 나오면 **1분 기다린 뒤** 다시 요청합니다.
- 오늘 2교시부터 이 키로 LLM 을 호출합니다. 같은 명령이나 같은 셀을 연달아 여러 번 실행하지 않습니다.
