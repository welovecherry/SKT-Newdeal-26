# 아침 과제 13 · 방화벽을 「기본 차단」으로 바꾸기 — networksim

10월 19일 (월) · 아침 과제

**오늘 하는 일:** 웹사이트 **networksim.app** 에서 모든 통신을 허용해 두어서 DB 까지 인터넷에 열려 있는 방화벽을 찾아, **기본 차단**으로 바꾸고 웹(443)만 허용합니다. 10/15 에 배운 허용 목록을 직접 해 보는 과제이고, 오늘 수업의 최소 권한과 이어집니다.

**오늘 못 끝냈으면 오후 5시 이후에 마무리합니다.**

---

## 1. 과제를 엽니다

**왜 중요한가** — 이 사이트에는 연습용 과제가 들어 있어서 따로 만들 것이 없습니다. 설치와 가입도 필요 없습니다.

1. **[브라우저]** 주소창에 `networksim.app` 을 입력해 엽니다. 화면이 영어이면 크롬 오른쪽 위의 번역 단추로 한국어로 바꿉니다.
2. **[networksim]** 위쪽 메뉴의 **Learn(배우기)** 을 눌러 **Tasks & challenges(작업 및 도전 과제)** 를 엽니다.
3. **[networksim]** 목록에서 **Default-deny: close the leaky firewall** 을 찾아 엽니다.

---

## 2. 처음 상태를 봅니다

**왜 중요한가** — 무엇이 문제인지 먼저 보아야 무엇을 고칠지 압니다.

1. **[networksim]** 과제 설명을 읽습니다. 「모든 통신을 허용(permit all)하는 방화벽이라 DB 까지 인터넷에서 닿는다」는 내용입니다.
2. **[networksim]** 과제의 시험 3개를 확인합니다. 지금 통과하지 못하는 시험이 어느 것인지 기록 파일(4번)에 적어 둡니다.

---

## 3. 방화벽을 고칩니다 (두 가지만)

**왜 중요한가** — 「모두 허용하고 위험한 것만 막는」 방식은 빠뜨린 것이 그대로 열립니다. 「모두 차단하고 필요한 것만 허용」으로 바꾸면 빠뜨려도 막힙니다. 10/15 의 허용 목록이 이것입니다.

1. **[networksim]** 그림에서 **방화벽** 기기를 더블클릭해 설정을 엽니다.
2. **[networksim]** 기본 정책(Default policy)을 **모두 차단(block everything, deny any)** 으로 바꿉니다.
3. **[networksim]** 규칙을 하나 추가합니다: **인터넷(outside) → DMZ, TCP 443, 허용(permit)**.

---

## 4. 확인하고 기록합니다

**왜 중요한가** — 시험이 모두 통과해야 제대로 고친 것입니다. 시험이 서로 다른 세 가지를 확인하는 이유를 적어 봅니다.

1. **[networksim]** 시험 3개가 모두 통과하는지 봅니다.
   - 인터넷 → 웹 서버(443): **통과**
   - 인터넷 → DB: **차단**
   - 인터넷 → 웹 서버의 다른 포트(80): **차단** (443 만 허용했기 때문)
2. **[터미널]** `security-agent-toolkit` 폴더에서 기록 파일을 만들고 확인합니다.
   ```bash
   pwd                          # 지금 위치를 보여 줍니다. …/security-agent-toolkit 으로 끝나야 합니다
   cd ..                        # network_zt 처럼 더 안쪽 폴더라면 한 칸 위로 올라갑니다 (이미 security-agent-toolkit 이면 건너뜁니다)
   touch docs/2026-10-19.md     # 오늘 기록 파일을 만듭니다
   ls docs                      # docs 폴더 안에 만든 파일이 보이는지 확인합니다
   ```
3. **[VS Code]** 왼쪽 목록에서 `docs/2026-10-19.md` 를 열고 아래 틀을 붙여 넣어 채웁니다.

## 막힐 때

- **과제 목록이 안 보일 때:** 메뉴의 영어 이름(**Learn → Tasks & challenges**)으로 찾습니다. 번역이 이름을 바꿔 놓았을 수 있습니다.
- **방화벽 설정이 어디인지 모를 때:** 그림의 방화벽 기기를 두 번 누릅니다. 설정 창이 열립니다.
- **시험이 계속 통과하지 못할 때:** 기본 정책이 「모두 차단」인지, 규칙의 방향이 인터넷에서 DMZ 쪽인지, 포트가 443 인지 하나씩 다시 봅니다.
