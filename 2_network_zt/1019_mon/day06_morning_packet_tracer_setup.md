# 선택 과제 · Cisco Packet Tracer 설치하고 처음 실행해 보기

선택 · 원하는 학생만 합니다 (10월 19일 아침 과제는 networksim 방화벽 과제입니다)

**오늘 하는 일:** 이번 주부터 네트워크 장치를 직접 놓고 연결하는 실습을 **Cisco Packet Tracer**(시스코 패킷 트레이서)로 합니다. 오늘 아침에는 **계정 만들기 → 설치 파일 받기 → 설치 → 처음 실행**까지 하고, 장치 세 개를 연결해 잘 동작하는지 확인합니다.

**Packet Tracer 란:** 스위치 · 라우터 · PC 를 화면에 놓고 선으로 연결해 보는 **네트워크 시뮬레이터**(simulator, 실제 장치 없이 동작을 흉내 내는 프로그램)입니다. 이번 주부터 이 프로그램으로 실습합니다.

**오늘 못 끝냈으면 오후 5시 이후에 마무리합니다.** 설치가 안 끝나면 수업 중 실습을 따라 하기 어렵습니다.

---

## 1. Cisco Networking Academy 계정을 만듭니다

**왜 중요한가** — Packet Tracer 는 무료지만, Cisco Networking Academy(시스코 네트워킹 아카데미, 줄여서 **NetAcad**) 계정으로 로그인해야 내려받고 실행할 수 있습니다. 계정이 없으면 다음 단계로 갈 수 없습니다.

1. **[브라우저]** 주소창에 `netacad.com` 을 입력해 접속하고, 회원 가입(Sign up) 화면으로 갑니다.
2. **[브라우저]** 화면의 안내대로 이름 · 이메일 · 비밀번호를 입력해 가입합니다. 이메일은 지금 바로 열어 볼 수 있는 주소를 씁니다.
3. **[브라우저]** 가입한 이메일로 온 **인증 메일**을 열어 확인 링크를 누릅니다. 메일이 보이지 않으면 스팸함도 봅니다.
4. **[메모]** 이메일과 비밀번호를 내가 볼 수 있는 곳에 적어 둡니다. 3번의 로그인에 씁니다. **기록 파일(5번)에는 적지 않습니다.**

---

## 2. 설치 파일을 내려받습니다

**왜 중요한가** — 설치 파일은 크기가 커서 내려받는 데 몇 분 걸립니다. 먼저 받기 시작해 두면 기다리는 동안 다른 단계를 준비할 수 있습니다. 내 PC 와 맞는 파일을 받아야 설치가 됩니다.

1. **[브라우저]** NetAcad 에 로그인한 상태에서 **Resource Hub**(리소스 허브) 의 Packet Tracer 내려받기 화면으로 갑니다. 검색창에 `Packet Tracer` 를 쳐서 찾을 수도 있습니다.
2. **[브라우저]** 내 PC 운영체제에 맞는 파일을 고릅니다. 학원 PC 는 **Windows 64비트**, 맥북은 **macOS** 입니다.
3. **[브라우저]** 내려받기가 끝나면 파일 이름과 크기를 확인합니다. 파일이 어디에 저장되었는지(보통 `다운로드` 폴더)도 봅니다.

---

## 3. 설치하고 로그인합니다

**왜 중요한가** — 로그인이 되어야 프로그램이 열립니다. 설치 중 선택을 바꾸면 이후 실습 화면과 달라질 수 있으니, 기본 선택대로 설치합니다.

1. **[탐색기 · Finder]** 내려받은 설치 파일을 더블클릭해 실행합니다. 권한을 묻는 창이 나오면 허용합니다.
2. **[설치 창]** 기본 선택을 바꾸지 않고 `Next` → 사용 동의 → `Install` 순서로 끝까지 진행합니다.
3. **[Packet Tracer]** 설치가 끝나면 프로그램을 실행합니다. 로그인 창이 나오면 1번에서 만든 NetAcad 계정으로 로그인합니다.
4. **[Packet Tracer]** 가운데 하얀 작업 화면과 왼쪽 아래 장치 목록이 보이면 설치 성공입니다.

---

## 4. 장치 세 개를 연결해 봅니다

**왜 중요한가** — 설치가 되었어도 장치를 놓고 선을 연결하는 기본 동작을 모르면 이번 주 실습을 따라갈 수 없습니다. 장치 세 개만 연결해 보면 오늘 설치가 제대로 되었는지도 확인됩니다.

1. **[Packet Tracer]** 왼쪽 아래 장치 종류 목록에서 **End Devices**(끝 장치)를 눌러 **PC** 를 작업 화면으로 끌어다 놓습니다. 같은 방법으로 PC 를 하나 더 놓습니다.
2. **[Packet Tracer]** 장치 종류 목록에서 **Network Devices**(네트워크 장치) → **Switches**(스위치)를 눌러 스위치 하나를 PC 두 대 사이에 놓습니다.
3. **[Packet Tracer]** 장치 종류 목록에서 **Connections**(연결) 의 **구리 직선 케이블**(Copper Straight-Through)을 고릅니다. PC 를 한 번 누르고 스위치를 눌러 연결하고, 다른 PC 도 스위치와 연결합니다. 연결할 때 나오는 포트 목록에서는 아무 포트나 고릅니다.
4. **[Packet Tracer]** 몇 초 기다립니다. 선 양 끝의 점이 **초록색**으로 바뀌면 연결된 것입니다.
5. **[Packet Tracer]** 메뉴에서 `Help` → `About` 을 열어 **설치한 버전 번호**를 적어 둡니다.

## 막힐 때

- **인증 메일이 오지 않을 때:** 스팸함을 봅니다. 가입 때 쓴 이메일 주소의 글자가 맞는지도 확인합니다.
- **내려받기가 너무 느릴 때:** 다른 창에서 큰 내려받기가 돌고 있지 않은지 봅니다. 파일이 커서 몇 분은 걸립니다.
- **설치가 중간에 멈추거나 권한 오류가 날 때:** 설치 창의 오류 문구를 읽고, 그 문구를 그대로 검색창에 붙여 넣어 봅니다. 해결되지 않으면 오류 화면을 캡처해 둡니다.
- **로그인이 안 될 때:** 1번에서 가입한 이메일과 비밀번호가 맞는지, 이메일 인증을 했는지 다시 봅니다.
