## 2교시 · nslookup

### 문제 2-1 · 도메인 이름을 IP 주소로 — 두 DNS 서버에 묻기

- (가-1) 처음 `nslookup example.com` 을 쳤을 때, 내가 물어본 DNS 서버의 주소와 example.com 의 IPv4 주소를 적어 주세요.
  - 쓸 내용: 화면 맨 위 `Address` 줄의 주소 하나, 아래쪽 `Addresses` 에서 숫자 네 개를 점으로 이은 주소 하나 — 두 개를 「서버: … / example.com: …」처럼. 맥북은 맨 위 `Address`, 아래 `Name:` 다음 `Address` 줄
  - 답:
- (가-2) `nslookup example.com 8.8.8.8` 을 쳤을 때, 맨 위 `서버` 줄에 나온 이름과 example.com 의 IPv4 주소를 적어 주세요.
  - 쓸 내용: `서버` 줄의 이름 하나(맥북은 `Server`), IPv4 주소 하나. 시간 초과가 났으면 「시간 초과」라고 적어도 됩니다
  - 답:
- (나) 🔍 화면 위쪽 `Address` 와 아래쪽 `Addresses` 는 각각 무엇의 주소일까요? 두 화면을 비교해서 적어 주세요.
  - 쓸 내용: ① 두 화면에서 바뀐 쪽과 그대로인 쪽 ② 그렇게 된 이유 — 위쪽 · 아래쪽이 각각 무엇의 주소인지를 근거로 쓰기
  - 답:
- (다-1) 회사 PC 가 회사 DNS 서버 대신 `8.8.8.8` 같은 외부 DNS 서버에 직접 묻고 있다면, 관제 담당자는 왜 이것을 확인해야 할까요?
  - 쓸 내용: ① 회사 DNS 서버가 평소에 하는 일(검색해서 찾아도 됩니다) ② 외부 DNS 에 직접 물으면 그 일을 거치지 않게 되는 까닭
  - 답:
- (다-2) 내 PC 의 DNS 서버 설정이 나도 모르게 낯선 주소로 바뀌어 있다면, 어떤 일이 생길 수 있을까요?
  - 쓸 내용: ① 그 낯선 DNS 서버가 내 질문에 어떤 답을 줄 수 있는지 ② 그 답 때문에 내가 어디로 접속하게 되는지
  - 답:

### 문제 2-2 · URL 에서 이름을 꺼내 묻기 — 없는 이름이면

- (가-1) `2-2_url_example.py` 를 실행했을 때 나온 두 줄을 그대로 옮겨 적어 주세요.
  - 쓸 내용: 터미널에 나온 출력 두 줄을 복사해 붙여 넣기
  - 답:
- (가-2) `2-2_url_nowhere.py` 의 맨 마지막 줄에 나온 에러 이름과, 같은 이름을 `nslookup` 했을 때 나온 문구를 적어 주세요.
  - 쓸 내용: 에러 이름은 마지막 줄의 `:` 앞부분 하나, `nslookup` 문구는 `Non-existent domain` 이 든 줄 하나(맥북은 `NXDOMAIN` 이 든 줄)
  - 답:
- (나-1) `parts[2]` 를 꺼냈더니 도메인 이름이 나왔습니다. 왜 번호 2 칸에 도메인 이름이 있을까요?
  - 쓸 내용: ① (가-1) 첫 줄의 리스트를 0 번부터 세어 각 칸에 무엇이 있는지 ② `//` 사이에 무엇이 생겼는지
  - 답:
- (나-2) 두 번째 파일은 왜 마지막 줄에서 에러가 나며 멈췄을까요? `nslookup` 결과와 이어서 적어 주세요.
  - 쓸 내용: ① `gethostbyname()` 이 DNS 서버에 무엇을 물었는지 ② DNS 서버가 어떤 답을 했는지 ③ 그래서 왜 에러가 났는지
  - 답:
- (다) 🔍 `Non-existent domain`(NXDOMAIN) 이 나왔다고 인터넷이 끊긴 걸까요? 아니라면 왜 아닌지 적어 주세요.
  - 쓸 내용: ① DNS 서버가 답을 했는지 안 했는지 ② 인터넷이 정말 끊겼다면 화면이 어떻게 달랐을지
  - 답:

## 4교시 · 레코드와 캐시

### 문제 4-1 · 메일 서버와 별칭 — MX · CNAME

- (가-1) `nslookup -type=mx google.com` 에서 메일 서버 이름(`mail exchanger =` 뒤)과 우선순위 숫자(`MX preference`)를 적어 주세요.
  - 쓸 내용: 메일 서버 이름 하나, 숫자 하나. 아래에 같이 나오는 IP 는 적지 않습니다
  - 답:
- (가-2) `nslookup www.naver.com` 에서 `Aliases:` 줄의 이름과 `이름:` 줄의 최종 이름을 적어 주세요.
  - 쓸 내용: `Aliases:` 에 나온 이름, `이름:` 에 나온 이름. 맥북은 `canonical name =` 뒤가 최종 이름입니다
  - 답:
- (나-1) MX 레코드는 왜 IP 가 아니라 서버 이름으로 답할까요? 그 서버의 IP 는 어떻게 알아낼까요?
  - 쓸 내용: ① 서버 이름으로 적어 두면 좋은 점(서버 IP 가 바뀌는 경우를 생각해 보세요) ② IP 를 알아내는 방법(안내 4.1 절의 표 참고)
  - 답:
- (나-2) `www.naver.com` 은 왜 다른 이름(정식 이름)을 가리키고 있을까요?
  - 쓸 내용: ① CDN 이 무엇인지 한 줄 ② 큰 사이트가 CNAME 으로 CDN 이름을 가리키게 하는 까닭
  - 답:
- (다) 🔍 의심스러운 메일을 받았을 때, 보낸 쪽 도메인의 MX 레코드를 확인하면 무엇을 알 수 있을까요?
  - 쓸 내용: ① 정상 회사 도메인의 MX 는 보통 어떤지 ② MX 가 없거나 낯설면 무엇을 의심할 수 있는지
