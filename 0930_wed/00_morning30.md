# 아침 과제 3 · 로그에서 필요한 줄만 골라내기

9월 30일 (수) · 아침 과제

**오늘 하는 일:** 로그 파일을 하나 만들고, 그 안에서 **필요한 줄만 골라내는 명령**을 익힙니다.

오늘 새로 쓰는 명령은 **두 개**입니다. 나머지는 그 명령에 글자 하나를 붙이는 것뿐입니다.

**오늘 못 끝냈으면 10/2(금) 아침에 이어서 합니다.** 오늘 오후는 다른 강사님 수업입니다.

---

## 1. 왜 이걸 배우는지 찾아봅니다

먼저 **왜 필요한지**를 직접 찾아보고 한두 줄로 적습니다.

| 질문 | 검색어 예시 |
|---|---|
| 보안 담당자는 서버에서 왜 `grep` 을 쓸까요? | `grep 이란`, `리눅스 로그 검색 grep`, `서버 로그 확인 방법` |

정답을 맞히는 과제가 아닙니다. **찾은 내용을 자기 말로 적는 것**이 과제입니다.

---

## 2. 이 말들이 무슨 뜻인지 찾아봅니다

검색해서 읽고 자기 말로 한 줄씩 적습니다.

| 찾아볼 말 | 무엇을 알아 오면 되나 (힌트) |
|---|---|
| grep (그렙) | 파일에서 무엇을 해 주는 명령인가 |
| 옵션 (option) | 명령 뒤에 무엇을 붙이는 것인가 |

오른쪽은 **힌트일 뿐입니다.** 뜻은 직접 찾아서 자기 말로 적습니다.

---

## 3. 오늘 쓸 로그 파일을 만듭니다

어제 기록 파일을 저장한 것과 **같은 방법**입니다. 메모장으로 만듭니다.

1. 메모장을 엽니다.
2. 아래 여덟 줄을 그대로 복사해 붙여 넣습니다.

```
2026-09-30 09:02:11 INFO accepted login for kim.cs
2026-09-30 09:12:00 WARN failed login for admin
2026-09-30 09:15:31 INFO accepted login for lee.yh
2026-09-30 10:03:19 WARN failed login for park.js
2026-09-30 11:20:55 INFO accepted login for choi.mk
2026-09-30 22:14:03 WARN failed login for admin
2026-09-30 22:14:21 WARN failed login for kim.cs
2026-09-30 23:40:07 warn failed login for guest
```

3. **파일 › 다른 이름으로 저장** 을 누릅니다.
4. 저장 위치를 `C:\Users\<내 계정>\security-agent-toolkit\logs` 로 합니다.
   그런 폴더가 없으면 저장 창에서 **새 폴더**로 `logs` 를 만듭니다.
5. 파일 이름을 `sample.log` 로 적고, 파일 형식을 **모든 파일**로 바꿔 저장합니다.

깃배시에서 그 폴더로 가서 파일이 있는지 봅니다.

```
$ cd ~/security-agent-toolkit/logs
$ ls
sample.log
```

`security-agent-toolkit` 폴더가 없으면 먼저 만듭니다.

```
$ cd ~
$ mkdir -p security-agent-toolkit/logs
```

---

## 4. 여섯 가지를 해 봅니다

**명령 이름만 알려 드립니다. 옵션은 직접 찾습니다.**

오늘 쓰는 명령은 `cat` 과 `grep` 둘입니다. 3번부터 6번까지는 `grep` 뒤에 **글자 하나**를 붙이면 됩니다.
「grep 줄 번호」처럼 검색하면 나옵니다.

| # | 하고 싶은 일 | 나오면 성공 |
|---|---|---|
| ① | 파일을 **통째로** 화면에 띄운다 | 여덟 줄이 다 보인다 |
| ② | **`WARN` 이 든 줄만** 본다 | 네 줄이 보인다 |
| ③ | 그 줄이 **몇 번째 줄인지** 함께 본다 | 줄 앞에 `2:` 처럼 번호가 붙는다 |
| ④ | `WARN` 이 **몇 줄에 나오는지 센다** | 숫자 하나만 나온다 |
| ⑤ | **대문자·소문자를 가리지 않고** `warn` 을 찾는다 | ②보다 한 줄 더 나온다 |
| ⑥ | **`admin` 이 안 든 줄만** 본다 | `admin` 줄이 빠진 나머지가 나온다 |

⑤에서 한 줄이 더 나오는 이유를 생각해 보세요. 마지막 줄을 보면 압니다.

⑥ 「이것만 빼고 보기」는 실무에서 자주 씁니다. 내 계정이나 점검용 장비를 빼고 볼 때 쓰지요.

## ⭐ 다 한 사람만 합니다

어제 오전에 배운 **정규표현식**이 터미널에도 있습니다. 아래 한 줄을 쳐 보세요.

```
$ grep -E "WARN|INFO" sample.log
```

`|` 는 「또는」입니다. 파이썬에서 쓴 것과 뜻은 같지만 **적는 규칙이 조금 다릅니다.**
`grep` 에서 정규식을 제대로 쓰려면 `-E` 를 붙여야 한다는 것만 기억하면 됩니다.
