# 아침 과제 11 · VS Code 를 내 것으로 커스터마이즈 하기

10월 15일 (목) · 아침 과제

**오늘 하는 일:** VS Code 를 내가 쓰기 편하게 바꿉니다. 메뉴를 한국어로 바꾸고, **AI 가 코드를 대신 채워 주는 기능은 확인해서 끕니다.**

**오늘 못 끝냈으면 오후 5시 이후에 마무리합니다.**

---

## 1. 테마를 바꿉니다 (다크 ↔ 라이트)

가볍게 몸을 풉니다.

1. Vscode 하단 왼쪽에 톱니바퀴를 누릅니다
2. Themes > Color Theme을 누릅니다.
3. **어두운 테마(Dark)** 와 **밝은 테마(Light)** 를 오가며 **눈에 편한 것**을 고릅니다.

정답은 없습니다. 밝은 곳에서는 라이트, 어두운 곳에서는 다크가 편한 경우가 많습니다.

---

## 2. Extention(확장)을 설치합니다

**설치 방법은 세 개 모두 같습니다.** Python · Jupyter 확장은 10/2 에 설치했습니다.

1. 왼쪽 세로 막대에서 **블록 네 개 모양 아이콘(확장)** 을 누릅니다. (또는 `Ctrl+Shift+X`)
2. 위 검색창에 이름을 칩니다.
3. 목록 맨 위 항목을 확인하고 **Install** 을 누릅니다. (한국어팩은 게시자가 **Microsoft** 입니다.)

### 필수

| 확장 | 검색어 | 왜 까나 |
|---|---|---|
| **Korean Language Pack** | `Korean Language Pack` (Microsoft) | 메뉴를 한국어로 바꿔 줍니다 |

### 선택 — 있으면 훨씬 편합니다

| 확장 | 검색어 | 왜 까나 |
|---|---|---|
| **Error Lens** | `Error Lens` | 틀린 곳을 **그 줄 옆에 빨간 글씨로 바로** 보여 줍니다 |
| **indent-rainbow** | `indent-rainbow` | 들여쓰기 깊이를 **색으로** 칠해 줍니다 (파이썬에서 특히 유용) |

---

## 3. 한국어팩을 적용합니다

한국어팩은 **설치만으로는 안 바뀌고**, 한 번 적용해 줘야 합니다.

1. 설치가 끝나면 오른쪽 아래에 **Change Language and Restart** 알림이 뜹니다. 그것을 누릅니다.
2. VS Code 가 껐다 켜지면서 메뉴가 **한국어**로 바뀝니다.

알림을 놓쳤다면 `Ctrl+Shift+P` → `Configure Display Language` → **한국어(ko)** 를 고르고 다시 시작합니다.

---

## 4. 터미널을 오른쪽으로 옮깁니다

터미널이 아래에 있으면 노트북이 좁게 보입니다. 오른쪽으로 옮기면 노트북과 터미널을 나란히 볼 수 있습니다.

1. 터미널 창 맨 위 줄(**TERMINAL** 글자가 있는 줄)의 **빈 곳을 오른쪽 클릭**합니다.
2. **Panel Position › Right**(패널 위치 › 오른쪽) 를 누릅니다.

위 메뉴 **View › Appearance › Panel Position › Right** 로도 같습니다. 다시 아래로 내리려면 같은 메뉴에서 **Bottom** 을 고릅니다. 한 번 옮기면 다음에도 오른쪽에 열립니다.

---

## 5. 코드를 대신 채워 주는 기능을 확인하고 끕니다 (필수)

10/2 아침 과제에서 이미 껐다면 꺼져 있는지 확인만 합니다.

배우는 단계에서는 **AI 가 코드를 대신 채워 주면 안 됩니다.** 지금 켜져 있는지 **먼저 확인**하고, 켜져 있으면 끕니다.

### 먼저 지금 상태를 봅니다
- 화면 **오른쪽 아래 상태 막대**에 **Copilot 아이콘(동그란 로봇 모양)** 이 있는지 봅니다. 있으면 켜져 있는 것입니다.
- 코드를 칠 때 **회색 글씨로 다음 내용이 미리** 나오면 켜져 있는 것입니다.

### 켜져 있으면 끕니다
1. 오른쪽 아래 **Copilot 아이콘을 누르고** → **Disable Completions**(또는 Disable Globally) 를 고릅니다.
2. 더 확실히 하려면 확장(`Ctrl+Shift+X`)에서 `Copilot` 을 검색해 **GitHub Copilot** 과 **GitHub Copilot Chat** 을 **사용 안 함(Disable)** 합니다.

### 아이콘이 없는데도 회색 글씨가 미리 채워지면
- `Ctrl+,` (설정) → 검색창에 `inline suggest` → **Editor › Inline Suggest: Enabled** 체크를 **해제**합니다.

⚠ `.` 을 쳤을 때 뜨는 **멤버 목록(IntelliSense)** 은 끄지 않습니다. 오타·속성 확인에 도움이 되는 다른 기능입니다.

## 6. 선택 사항 (유용한 extention)

Error Lens 와 indent-rainbow 가 화면에서 어떻게 보이는지만 확인합니다.

1. **파일 › 새 파일** 을 누르고, `test.py` 라는 이름으로 아무 폴더에나 저장합니다.
2. 아래를 그대로 적습니다.

   ```python
   def hello():
       name = "kim"
       print(name
   ```

3. 두 가지를 봅니다.
   - **indent-rainbow** — 들여쓴 두 줄 앞에 **색 막대**가 생깁니다.
   - **Error Lens** — 마지막 줄 `print(name` 은 괄호를 안 닫아서, **그 줄 옆에 빨간 글씨로 오류**가 뜹니다.
4. 마지막 줄 끝에 `)` 를 채워 넣습니다. **빨간 표시가 사라집니다.**

빨간 표시가 늦게 뜨면 잠깐 기다립니다. 확인이 끝나면 `test.py` 는 지워도 됩니다.
