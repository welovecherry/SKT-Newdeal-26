# 아침 과제 2 · 폴더 만들기와 경로 이동

9월 29일 (화) · 아침 과제

**오늘 하는 일:** 앞으로 공부한 것을 모아 둘 폴더를 만들고, 그 안으로 들어가고 나옵니다.

**오전에 다 못 했으면 오후 5시 이후에 마무리합니다.** 오늘 안에 4번 확인까지 끝내면 됩니다.

---

## 1. 먼저 이 말들을 공부합니다

검색해서 읽고 스스로 정리해 봅니다. 정리한 것은 남에게 안 보고 설명할 수 있도록 복습합니다.

### 위치를 가리키는 말

| 찾아볼 말 | 이런 내용이 나옵니다 |
|---|---|
| 폴더 · 디렉터리 | 같은 것을 부르는 두 이름입니다. 명령어 쪽에서는 디렉터리라고 씁니다 |
| 절대경로 | 맨 위부터 전부 적은 주소 — `/c/Users/hong/Desktop` |
| 상대경로 | 지금 있는 위치를 기준으로 적은 주소 — `Desktop`, `..` |
| 홈 디렉터리 | 로그인한 사용자에게 주어진 기본 폴더. `~` 로 줄여 씁니다 |
| `.` 과 `..` | `.` 은 지금 있는 폴더, `..` 는 한 칸 위 폴더입니다 |
| `/` 와 `\` | 윈도우는 `\`, 리눅스·맥은 `/` 를 씁니다. 깃배시는 `C:\Users\hong` 을 `/c/Users/hong` 으로 적습니다 |

### 명령 이름의 뜻

명령 이름은 대부분 영어 줄임말입니다. 원래 말을 찾아보면 외우지 않아도 뜻이 남습니다.

| 명령 | 무엇의 줄임말인지 찾아봅니다 |
|---|---|
| `pwd` | |
| `ls` | |
| `cd` | |
| `mkdir` | |

### 명령 한 줄의 구조

명령은 이렇게 생겼습니다.

```
mkdir docs        명령 + 대상
ls -a             명령 + 옵션
cd ..             명령 + 대상(한 칸 위)
```

「옵션」 또는 「플래그」가 무엇인지 찾아봅니다. 어제 쓴 `-a` 가 옵션입니다.

### 치기 전에 알아 둘 것 세 가지

1. 대소문자를 구분합니다. `LS` 는 실행되지 않습니다.
2. 이름에 빈칸이 있으면 따옴표로 감쌉니다. `cd "My Documents"`
3. 엔터를 누를 때 실행됩니다. 그 전까지는 고칠 수 있습니다.

### 스스로 설명해 봅니다

정리한 것을 보지 않고 답해 봅니다. 막히면 위로 돌아가 다시 읽습니다.

- 지금 있는 폴더를 화면에 띄우는 명령은 무엇입니까?
- `cd ..` 를 입력하면 어디로 갑니까?
- `/c/Users/hong` 을 윈도우 탐색기 주소창에 적으면 어떤 모양이 됩니까?

---

## 2. 폴더를 만들고 들어갑니다

한 줄 입력하고 엔터를 누릅니다. 아래는 강사 PC 의 출력입니다.

### ① 홈으로 갑니다

```
$ cd ~
$ pwd
/c/Users/hong
```

### ② 폴더를 하나 만듭니다

이 폴더는 이번 과정 내내 씁니다. 이름을 그대로 씁니다.

```
$ mkdir security-agent-toolkit
$ ls
Desktop  Documents  Downloads  security-agent-toolkit
```

### ③ 그 폴더 안으로 들어갑니다

```
$ cd security-agent-toolkit
$ pwd
/c/Users/hong/security-agent-toolkit
```

### ④ 안에 폴더 두 개를 더 만듭니다

```
$ mkdir agent_core
$ mkdir docs
$ ls
agent_core  docs
```

`agent_core` 는 앞으로 만드는 파이썬 파일을 두는 곳이고, `docs` 는 공부 기록을 두는 곳입니다.

### ⑤ 한 칸 위로 나옵니다

`..` 는 한 칸 위 폴더를 뜻합니다.

```
$ cd ..
$ pwd
/c/Users/hong
```

---

## 3. 기록 파일을 그 폴더에 만듭니다

어제는 메모장에 적기만 했습니다. 오늘은 만든 폴더 안에 파일로 저장합니다.

1. 메모장을 엽니다.
2. 아래 네 칸을 적습니다.
3. **파일 › 다른 이름으로 저장** 을 누릅니다.
4. 저장 위치를 `C:\Users\<내 계정>\security-agent-toolkit\docs` 로 옮깁니다.
5. 파일 이름을 `2026-09-29.md` 로 적고, 파일 형식을 **모든 파일**로 바꿔 저장합니다.

```markdown
# 2026-09-29 (화)

## 오늘 새로 쓴 명령
cd, cd .., cd ~, mkdir

## 찾아보고 알게 된 것
`..` 는 한 칸 위 폴더를 뜻한다.

## 막힌 것
저장할 때 파일 이름이 2026-09-29.md.txt 로 저장됐다.

## 다음에 확인할 것
폴더 이름에 빈칸이 있으면 어떻게 쓰나.
```

깃배시에서 잘 저장됐는지 확인합니다.

```
$ ls security-agent-toolkit/docs
2026-09-29.md
```

## ⭐ 다 한 사람만 합니다

`docs` 안에 있는 상태에서, **홈으로 돌아가지 않고** `agent_core` 로 바로 이동해 봅니다.
`..` 를 쓰면 됩니다. 성공하면 그때 입력한 명령을 기록 파일에 적어 둡니다.
