# 아침 과제 8 · Wireshark 설치하고 새 과목 폴더 만들기

10월 12일 (월) · 아침 과제

**오늘 하는 일:** 오후 실습에 쓸 **Wireshark**(와이어샤크 · 오가는 패킷을 붙잡아 보여 주는 프로그램)를 설치하고, 오늘부터 쓸 과목 폴더 **`network_zt`** 를 만듭니다.

설치는 **기다리는 시간이 대부분**입니다. 설치를 먼저 걸어 두고, 도는 동안 폴더를 만듭니다.

**⚠ 이 과제는 점심시간 전까지 꼭 끝냅니다.** 오후 6교시 실습이 Wireshark 로 시작합니다.

---

## 1. 왜 이걸 설치하는지 찾아봅니다

먼저 **왜 필요한지**를 직접 찾아보고 한두 줄로 적습니다.

| 질문 | 검색어 예시 |
|---|---|
| 보안 담당자는 왜 패킷을 직접 열어 볼까요? | `와이어샤크 란`, `패킷 분석 보안 관제` |

정답을 맞히는 과제가 아닙니다. **찾은 내용을 자기 말로 적는 것**이 과제입니다.

---

## 2. 이 말들이 무슨 뜻인지 찾아봅니다

검색해서 읽고 자기 말로 한 줄씩 적습니다.

| 찾아볼 말 | 무엇을 알아 오면 되나 (힌트) |
|---|---|
| 패킷 (packet) | 네트워크로 보내는 데이터의 무엇인가 |
| 패킷 캡처 (packet capture) | 무엇을 붙잡는 것인가 |
| Npcap (엔피캡) | Wireshark 와 어떤 관계인가 |

오른쪽은 **힌트일 뿐입니다.** 뜻은 직접 찾아서 자기 말로 적습니다.

---

## 3. Wireshark 설치를 먼저 걸어 둡니다

**① 설치 파일을 받습니다**

1. 브라우저에서 `https://www.wireshark.org/download.html` 을 엽니다.
2. 맨 위 **Stable Release**(안정판) 아래에서 **Windows x64 Installer** 를 누릅니다.

| 목록에 보이는 것 | 고르나 | 이유 |
|---|---|---|
| **Windows x64 Installer** | ✅ 이것 | 학원 PC 같은 일반 Windows PC 용 설치 파일 |
| Windows Arm64 Installer | ❌ | ARM 칩을 쓰는 일부 노트북용 |
| Windows x64 PortableApps | ❌ | 설치 없이 쓰는 판 — 패킷을 붙잡는 부품(Npcap)이 같이 깔리지 않는다 |

**② 받은 파일을 실행합니다**

1. 내려받은 `Wireshark-…-x64.exe` 를 엽니다.
2. 「이 앱이 디바이스를 변경하도록 허용하시겠어요?」 창이 뜨면 **예** 를 누릅니다.
3. 그다음부터는 **Next**(다음)를 누르며 넘어갑니다. 아래 두 화면에서만 멈춰서 확인합니다.

| 화면 | 할 일 |
|---|---|
| **Packet Capture**(패킷 캡처) — `Install Npcap` 체크 칸 | **체크를 켠 채로 둡니다.** 이것이 빠지면 오후에 패킷을 하나도 못 잡습니다 |
| **USB Capture** — `Install USBPcap` 체크 칸 | 꺼도 됩니다. USB 장치용이라 이 수업에서는 쓰지 않습니다 |

4. 설치 중에 **Npcap 설치 창이 따로 뜨면** 기본값 그대로 **I Agree**(동의) → **Install**(설치) → **Next** → **Finish**(마침)를 누릅니다.
5. Wireshark 설치 창으로 돌아와 **Finish** 를 누릅니다.

**설치가 도는 동안 바로 4번으로 넘어갑니다.**

---

## 4. 새 과목 폴더를 만듭니다

오늘부터 2과목 「네트워크·ZT 운영」입니다. 과목마다 폴더를 하나씩 씁니다. 지금까지는 `agent_core`, 오늘부터는 **`network_zt`** 입니다.

**① `network_zt` 폴더를 만듭니다**

1. VS Code 에서 `security-agent-toolkit` 폴더를 엽니다.
2. 왼쪽 파일 목록의 **빈 곳을 오른쪽 클릭**하고 **New Folder**(새 폴더)를 누릅니다.
3. 이름을 `network_zt` 로 적습니다. `agent_core` · `docs` 와 **같은 높이**에 있어야 합니다.

**② 터미널을 그 폴더에서 엽니다**

`network_zt` 폴더를 오른쪽 클릭하고 **Open in Integrated Terminal**(통합 터미널에서 열기)을 누릅니다.

```
$ pwd
```

- 결과가 `…/security-agent-toolkit/network_zt` 로 끝나면 됩니다. 앞부분은 사람마다 다릅니다.

---

## 5. Wireshark 가 잘 깔렸는지 봅니다

설치가 끝났으면 시작 메뉴에서 **Wireshark** 를 엽니다.

| 나와야 하는 것 | 안 나오면 |
|---|---|
| 창 가운데 `Welcome to Wireshark` 아래에 **이더넷 · Wi-Fi 같은 통로 이름 목록** | 목록이 비어 있으면 Npcap 이 빠진 것입니다. 설치 파일을 다시 실행해 `Install Npcap` 을 켭니다 |
| 이름 오른쪽에 **작은 그래프**가 움직인다 | 움직이는 줄이 지금 쓰는 통로입니다. 학원 PC 는 대개 `이더넷` 입니다 |

**캡처는 아직 누르지 않습니다.** 오후 6교시에 함께 합니다. 확인했으면 Wireshark 를 닫습니다.
