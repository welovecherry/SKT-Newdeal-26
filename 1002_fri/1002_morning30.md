# 아침 과제 4 · VS Code 를 내 것으로 커스터마이즈 하기

10월 2일 (금) · 아침 과제

**오늘 하는 일:** 이미 설치한 VS Code 에 **확장(extension) 다섯 개**를 깔고, 내가 쓰기 편하게 바꿉니다.

**오늘 못 끝냈으면 오후 5시 이후에 마무리합니다.**

---

## 1. 왜 이걸 하는지 찾아봅니다

먼저 **왜 확장을 깔아 쓰는지**를 직접 찾아보고 한두 줄로 적습니다.

| 질문 | 검색어 예시 |
|---|---|
| VS Code extention은 무엇이고 왜 쓸까요? | `vscode extension 이란`, `vscode 확장 추천`, `코드 에디터 확장 기능` |

---

## 2. 이 말들이 무슨 뜻인지 찾아봅니다

검색해서 읽고 자기 말로 한 줄씩 적습니다.

| 찾아볼 말 | 이런 내용이 나옵니다 |
|---|---|
| 확장 (extension) | 편집기에 기능을 더 붙이는 추가 프로그램 |
| 명령 팔레트 (command palette) | 기능을 이름으로 찾아 실행하는 검색창 (`Ctrl+Shift+P`) |

---

## 3. 테마를 바꿉니다 (다크 ↔ 라이트)

가볍게 몸을 풉니다.

1. Vscode 하단 왼쪽에 톱니바퀴를 누릅니다
2. Themes > Color Theme을 누릅니다.
3. **어두운 테마(Dark)** 와 **밝은 테마(Light)** 를 오가며 **눈에 편한 것**을 고릅니다.

정답은 없습니다. 밝은 곳에서는 라이트, 어두운 곳에서는 다크가 편한 경우가 많습니다.

---

## 4. Extention(확장)을 설치합니다

**설치 방법은 다섯 개 모두 같습니다.**

1. 왼쪽 세로 막대에서 **블록 네 개 모양 아이콘(확장)** 을 누릅니다. (또는 `Ctrl+Shift+X`)
2. 위 검색창에 이름을 칩니다.
3. 목록 맨 위 항목을 확인하고 **Install** 을 누릅니다. (Python·Jupyter·한국어팩은 게시자가 **Microsoft** 입니다.)

### 필수 — 앞으로 반드시 씁니다

| 확장 | 검색어 | 왜 까나 |
|---|---|---|
| **Python** | `Python` (Microsoft) | 다음 주 로컬에서 파이썬을 실행할 때 씁니다. 오늘은 깔아만 둡니다 |
| **Jupyter** | `Jupyter` (Microsoft) | 노트북(`.ipynb`) 을 VS Code 에서 열고 실행할 때 씁니다 |
| **Korean Language Pack** | `Korean Language Pack` (Microsoft) | 메뉴를 한국어로 바꿔 줍니다 |

### 선택 — 있으면 훨씬 편합니다

| 확장 | 검색어 | 왜 까나 |
|---|---|---|
| **Error Lens** | `Error Lens` | 틀린 곳을 **그 줄 옆에 빨간 글씨로 바로** 보여 줍니다 |
| **indent-rainbow** | `indent-rainbow` | 들여쓰기 깊이를 **색으로** 칠해 줍니다 (파이썬에서 특히 유용) |

---

## 5. 한국어팩을 적용합니다

한국어팩은 **설치만으로는 안 바뀌고**, 한 번 적용해 줘야 합니다.

1. 설치가 끝나면 오른쪽 아래에 **Change Language and Restart** 알림이 뜹니다. 그것을 누릅니다.
2. VS Code 가 껐다 켜지면서 메뉴가 **한국어**로 바뀝니다.

알림을 놓쳤다면 `Ctrl+Shift+P` → `Configure Display Language` → **한국어(ko)** 를 고르고 다시 시작합니다.

---

## 6. 선택 사항 (유용한 extention)

**코드를 실행하지 않습니다.** Error Lens 와 indent-rainbow 가 화면에서 어떻게 보이는지만 확인합니다.

1. **파일 › 새 파일** 을 누르고, `test.py` 라는 이름으로 아무 폴더에나 저장합니다.
2. 아래를 그대로 적습니다.

   ```python
   def hello():
       name = "kim"
       print(name
   ```

3. 두 가지를 봅니다.
   - **indent-rainbow** — 들여쓴 두 줄 앞에 **색 막대**가 생깁니다.
   - **Error Lens** — 마지막 줄 `print(name` 은 괄호를 안 닫아서, **그 줄 옆에 빨간 글씨로 오류**가 뜹니다.
4. 마지막 줄 끝에 `)` 를 채워 넣습니다. **빨간 표시가 사라집니다.**

빨간 표시가 늦게 뜨면 잠깐 기다리거나 `Ctrl+S` 로 저장해 봅니다. 확인이 끝나면 `test.py` 는 지워도 됩니다.

## 7. 오늘 바꾼 것을 파일로 남깁니다

**메모장 대신 VS Code 로 만듭니다.**

1. VS Code 에서 **파일 › 새 파일** 을 누릅니다.
2. 아래 내용을 적습니다.
3. **파일 › 저장** 을 누르고 `docs` 폴더에 `2026-10-02.md` 로 저장합니다.

```markdown
# 2026-10-02 (금)

## 내가 고른 테마
(다크인지 라이트인지)

## 깐 확장
(필수 3개 · 선택 몇 개)

## Error Lens · indent-rainbow 를 보고 느낀 것

## 막힌 것

## 다음에 확인할 것
```

파일 이름 끝을 `.md` 로 저장하면 **메모장과 달리 `.txt` 가 안 붙습니다.** 9/29 에 겪은 그 문제가 없어집니다.

## ⭐ 다 한 사람만 합니다

VS Code 안에도 **터미널**이 들어 있습니다.

1. 위 메뉴에서 **터미널 › 새 터미널** 을 누릅니다.
2. 아래쪽에 창이 열립니다. 깃배시와 같은 자리입니다.
3. `ls` 를 쳐 봅니다. 지금 열려 있는 폴더의 파일이 **글자로** 나옵니다.

**같은 폴더를 왼쪽은 마우스로, 아래는 글자로 보고 있습니다.**
오늘 3교시에 이 둘의 차이를 배웁니다 — 마우스로 누르는 방식(GUI)과 글자로 적는 방식(CLI)입니다.

⚠ 파이썬은 아직 안 깔았습니다. 터미널에서 `python` 을 쳐도 안 됩니다. **정상입니다.**
