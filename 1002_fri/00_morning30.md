# 아침 과제 4 · VS Code 로 내 폴더 열기

10월 2일 (금) · 아침 과제

**오늘 하는 일:** VS Code 를 설치하고, 지금까지 만든 파일들을 **한 화면에서** 열어 봅니다.

**파이썬은 건드리지 않습니다.** 오늘은 VS Code 를 **글 쓰는 프로그램**으로만 씁니다.

**오늘 못 끝냈으면 오후 5시 이후에 마무리합니다.**

---

## 1. 왜 이걸 쓰는지 찾아봅니다

먼저 **왜 필요한지**를 직접 찾아보고 한두 줄로 적습니다.

| 질문 | 검색어 예시 |
|---|---|
| 개발자는 왜 메모장 대신 VS Code 를 쓸까요? | `vscode 란`, `코드 에디터 왜 쓰나`, `IDE 메모장 차이` |

---

## 2. 이 말들이 무슨 뜻인지 찾아봅니다

검색해서 읽고 자기 말로 한 줄씩 적습니다.

| 찾아볼 말 | 이런 내용이 나옵니다 |
|---|---|
| 편집기 (editor) | 글자를 쓰고 고치는 프로그램 |
| 구문 강조 (syntax highlighting) | 코드의 갈래마다 색을 다르게 칠해 주는 것 |

---

## 3. VS Code 를 설치합니다

`vscode 다운로드` 로 검색해 공식 페이지에서 내려받습니다.

설치 화면에서 **고를 것이 없습니다.** 계속 다음을 누르면 됩니다.
깃배시처럼 바꿔야 하는 항목은 없습니다.

---

## 4. 드라이브에서 `agent_core` 폴더를 내려받습니다

지금까지 만든 파일들은 **내 구글 드라이브**에 있습니다. 그것을 내 컴퓨터로 가져옵니다.

1. `drive.google.com` 을 엽니다.
2. `agent_core` 폴더에 오른쪽 클릭 → **다운로드** 를 누릅니다.
3. 압축 파일(`.zip`)로 받아집니다. **압축을 풉니다.**
4. 푼 폴더 **안의 파일들을** `security-agent-toolkit\agent_core` 로 옮깁니다.
   그 폴더는 9/29 아침에 이미 만들어 두었습니다. 비어 있는 것이 정상입니다.

---

## 5. VS Code 로 그 폴더를 엽니다

1. VS Code 를 실행합니다.
2. 위 메뉴에서 **파일 › 폴더 열기** 를 누릅니다.
3. 방금 옮긴 `agent_core` 폴더를 고릅니다.

왼쪽에 파일 목록이 뜹니다. **나흘 동안 만든 것이 한 화면에 다 보입니다.**

| 있어야 하는 파일 | 언제 만들었나 |
|---|---|
| `log_parser.py` · `agent.log` | 9/28 오전 |
| `normalize_logs.py` · `normalized_logs.json` | 9/28 오후 |
| `unmatched_logs.txt` | 9/29 오전 |
| `api_client.py` · `.env.example` · `api_result.json` | 9/30 오전 |

없는 파일이 있으면 그날 노트북의 드라이브 저장 문제로 돌아가 다시 하면 됩니다. **오늘 다 없어도 됩니다.**

---

## 6. 열어서 두 가지를 봅니다

### ① `log_parser.py` 를 눌러 봅니다

**색이 칠해져 있습니다.** 메모장에서 본 것과 견줘 보세요.

| 무엇 | 메모장 | VS Code |
|---|---|---|
| `import`·`try` 같은 말 | 검은 글자 | 색이 다르다 |
| `"파서 시작"` 같은 글자 값 | 검은 글자 | 또 다른 색 |
| 줄 번호 | 없다 | 왼쪽에 있다 |

### ② `agent.log` 를 눌러 봅니다

메모장으로 열지 않아도 내용이 그대로 보입니다. 같은 것을 **터미널에서 글자로** 보는 법은 10/6 아침에 합니다.

---

## 7. 오늘 공부한 것을 파일로 남깁니다

**이번에는 메모장 대신 VS Code 로 만듭니다.**

1. VS Code 에서 **파일 › 새 파일** 을 누릅니다.
2. 아래 내용을 적습니다.
3. **파일 › 저장** 을 누르고 `docs` 폴더에 `2026-10-02.md` 로 저장합니다.

```markdown
# 2026-10-02 (금)

## 내 agent_core 에 있는 파일
(왼쪽 목록에 보이는 것을 적습니다)

## 메모장과 VS Code 의 차이
(직접 보고 느낀 것을 적습니다)

## 막힌 것

## 다음에 확인할 것
```

파일 이름 끝을 `.md` 로 저장하면 **메모장과 달리 `.txt` 가 안 붙습니다.** 9/29에 겪은 그 문제가 없어집니다.
