# 5교시 (14:00–14:50) · 스위치와 라우터 · 다음 홉

### 왜 필요한가

1. PC 는 패킷을 보내기 전에 **목적지가 같은 망인지**부터 계산합니다. 같으면 스위치로 바로, 다르면 **기본 게이트웨이**로 보냅니다.
2. 관제에서 「같은 층 PC 끼리는 되는데 다른 부서로만 안 된다」 같은 문의는 대부분 이 갈림길에서 생깁니다.
3. 게이트웨이를 다른 망 주소로 잘못 적으면 **선이 멀쩡해도** 밖으로 못 나갑니다. 조용한 장애의 대표입니다.

### 5.1 두 장비가 하는 일

| | 스위치(switch) | 라우터(router) |
|---|---|---|
| 층 | 2층(데이터링크) | 3층(네트워크) |
| 보는 주소 | **MAC 주소** | **IP 주소** |
| 잇는 범위 | **같은 망** 안의 장비들 | **다른 망** 사이 |
| 기억하는 표 | MAC 주소 표 — 「이 MAC 은 몇 번 포트」 | 라우팅 표(routing table) — 「이 망으로 가려면 다음은 누구」 |

### 5.2 다른 망으로 보낼 때 무엇이 바뀌나

PC `192.168.10.10/26` 이 다른 망의 서버 `192.168.10.70` 으로 보낼 때:

| 칸 | 값 | 바뀌나 |
|---|---|---|
| 목적지 **IP** | `192.168.10.70` (최종 목적지) | 끝까지 **그대로** |
| 목적지 **MAC** | **게이트웨이의 MAC** | 장비를 하나 지날 때마다 **바뀐다** |

- **다음 홉**(next hop · 넥스트 홉): 지금 장비가 패킷을 **바로 넘겨줄 이웃 장비**. PC 의 다음 홉은 기본 게이트웨이입니다.
- 그래서 `arp -a` 에는 **게이트웨이의 MAC** 은 있어도, 인터넷 건너편 서버의 MAC 은 없습니다(5-4).

### 5.3 스위치가 MAC 을 배우는 법

1. 프레임(frame · 2층에서 주고받는 데이터 묶음)이 들어오면 **출발지 MAC 과 들어온 포트**를 표에 적습니다.
2. 목적지 MAC 이 **표에 있으면** 그 포트 하나로만 보냅니다.
3. **없으면** 들어온 포트를 뺀 모든 포트로 복사해 보냅니다 — 이것이 **플러딩**(flooding)입니다.

#### 🐍 문법 상자 · 사전에 키가 있나 · 리스트에 하나씩 더하기

```python
mac_table = {"AA": 1}
print("AA" in mac_table, "BB" in mac_table)
out = []
for port in [1, 2, 3, 4]:
    if port != 1:
        out.append(port)
print(out)
# True False
# [2, 3, 4]
```

| 쓰는 것 | 뜻 |
|---|---|
| `키 in 사전` | 사전에 그 **키**가 있나 (1과목) |
| `리스트.append(값)` | 리스트 끝에 하나 더한다 |
| `!=` | 같지 않다 |

⚠ `mac_table["BB"]` 처럼 없는 키를 바로 꺼내면 `KeyError` 입니다. 먼저 `in` 으로 확인합니다.

# 6교시 (15:00–15:50) · VLAN · 라우팅 표 · 기본 경로

### 왜 필요한가

1. 부서마다 스위치를 따로 사면 비쌉니다. **스위치 하나를 여러 망으로 나누는 것**이 VLAN 입니다.
2. VLAN 이 다르면 **같은 스위치에 꽂혀 있어도** 직접 못 주고받습니다. 개발팀 PC 가 감염돼도 보안팀 망으로 바로 퍼지지 않습니다.
3. VLAN 사이를 오가려면 라우터가 필요하고, 라우터는 **라우팅 표**를 보고 길을 고릅니다. 내 PC 에도 라우팅 표가 있습니다.

### 6.1 VLAN 과 서브넷

| | 서브넷 | VLAN(Virtual LAN · 가상 랜) |
|---|---|---|
| 나누는 층 | 3층 — IP 주소와 마스크로 | 2층 — 스위치 **포트 설정**으로 |
| 정하는 곳 | PC 의 IP 설정 | 스위치 |
| 운영 규칙 | **VLAN 하나 = 서브넷 하나**로 짝을 맞춘다 | 〃 |

| 포트 종류 | 연결하는 것 | VLAN |
|---|---|---|
| 액세스 포트(access port) | PC · 프린터 | **하나**만 |
| 트렁크 포트(trunk port) | 스위치 ↔ 스위치 · 스위치 ↔ 라우터 | 여러 개를 한 선으로 — 번호표(태그)를 붙여서 |

⚠ 서로 다른 VLAN 에 **같은 서브넷**을 주면, PC 는 같은 망이라 생각해 게이트웨이로 안 보내고, 스위치는 VLAN 이 달라 막습니다 — 라우터가 있어도 안 됩니다(⭐6-6).

### 6.2 라우팅 표와 기본 경로

> 🔎 **검색해서 채웁니다.** 표의 `🔎` 칸은 비워 두었습니다. 검색하고 💻 직접 실행해 확인한 뒤, 오늘 보고서 맨 아래 `## 찾아본 것` 에 **내 말로 한 줄씩** 적습니다. 다 적은 뒤 맨 아래 「정답」의 표와 비교합니다.
> 검색어 예: `라우팅 테이블 기본 경로` · `default route 0.0.0.0/0`
> ⚠ 검색 결과는 영어 · 리눅스 화면이 많습니다. 내 화면(한국어 Windows)의 글자와 짝을 맞춰 읽습니다.

| 목적지 망 | 다음 홉 | 뜻 |
|---|---|---|
| `192.168.10.0/26` | 직접 연결 | 내 망 — 스위치로 바로 |
| `0.0.0.0/0` | `192.168.10.1` | 🔎 **기본 경로**(default route) 는 어떤 목적지에 쓰이나? `route print` 에서는 어느 줄인가? |

- 맞는 줄이 여러 개면 **CIDR(사이더) 숫자가 가장 큰(가장 좁은) 줄**을 고릅니다. `0.0.0.0/0` 은 모든 주소에 맞지만 숫자가 0 이라 맨 마지막 선택지입니다.
- Windows 는 `route print`(루트 프린트) 로 내 PC 의 라우팅 표를, `tracert`(트레이스 라우트) 로 거쳐 가는 다음 홉들을 보여 줍니다.

#### 🐍 문법 상자 · `.prefixlen` — CIDR 숫자 꺼내기

```python
import ipaddress
a = ipaddress.ip_network("0.0.0.0/0")
b = ipaddress.ip_network("192.168.10.64/26")
dest = ipaddress.ip_address("192.168.10.70")
print(dest in a, dest in b)
print(a.prefixlen, b.prefixlen)
# True True
# 0 26
```

| 쓰는 것 | 뜻 |
|---|---|
| `망.prefixlen` | CIDR 숫자 — 클수록 좁은(구체적인) 망 |
| `주소 in 망` | 그 줄이 맞는가 |

⚠ 맞는 줄이 둘 이상이면 `prefixlen` 이 **큰** 쪽입니다. 먼저 맞은 줄을 고르면 기본 경로로 엉뚱하게 갈 수 있습니다.

### ✍️ 문제 6-5 · 라우팅 표에서 길 고르기 (`route_lookup.py`)

목적지마다 **맞는 줄 가운데 CIDR 숫자가 가장 큰 줄**의 다음 홉을 고르시오.

```python
import ipaddress

# ── 미리 채워 둔 줄입니다. 고치지 않습니다 ──
routes = [                                        # (목적지 망, 다음 홉)
    ("0.0.0.0/0", "인터넷 게이트웨이"),
    ("192.168.10.0/26", "직접 연결 G0/0"),        # G0/0 · G0/1 은 라우터의 포트 이름
    ("192.168.10.64/26", "직접 연결 G0/1"),
]
# ── 여기까지 ──


def lookup(dest):                                 # 목적지 주소의 다음 홉을 돌려준다
    dest = ipaddress.ip_address(dest)
    best = None                                   # 지금까지 고른 줄
    for cidr, hop in routes:                      # 표를 한 줄씩
        net = ipaddress.ip_network(cidr)
        # 1. dest 가 net 안에 있고, best 가 None 이거나 net.prefixlen 이 best 의 prefixlen 보다 크면 best 에 (net, hop) 을 담으세요

    return best[1]                                # 고른 줄의 다음 홉


for d in ["192.168.10.20", "192.168.10.70", "8.8.8.8"]:
    print(d, "→", lookup(d))
```

| | |
|---|---|
| 🎯 나와야 하는 결과 | `192.168.10.20 → 직접 연결 G0/0` · `192.168.10.70 → 직접 연결 G0/1` · `8.8.8.8 → 인터넷 게이트웨이` |

**💡 힌트**

1. `best[0].prefixlen` 이 지금까지 고른 줄의 CIDR 숫자입니다.
2. `best is None or …` 으로 처음 맞은 줄도 받습니다.
3. `0.0.0.0/0` 은 늘 맞지만 숫자가 0 이라 더 좁은 줄에 집니다.

### 정답 5-3

```python
PORTS = [1, 2, 3, 4]                              # 스위치의 포트 네 개
mac_table = {}                                    # 처음엔 아무것도 모른다


def receive(in_port, src, dest):                  # 프레임 하나가 in_port 로 들어왔다
    # 1. mac_table 의 src 키에 in_port 를 담으세요 (출발지를 배운다)
    mac_table[src] = in_port                      # 이 MAC 은 이 포트에 있다
    # 2. dest 가 mac_table 에 있으면 [mac_table[dest]] 를 return 하세요
    if dest in mac_table:                         # 목적지를 안다면
        return [mac_table[dest]]                  # 그 포트 하나로만
    out = []                                      # 모르면 플러딩할 포트들
    for port in PORTS:
        # 3. port 가 in_port 가 아니면 out 에 더하세요
        if port != in_port:                       # 들어온 포트는 빼고
            out.append(port)
    return out


print("AA → BB :", receive(1, "AA", "BB"))       # BB 를 아직 모른다
print("BB → AA :", receive(3, "BB", "AA"))       # AA 는 1번에서 배웠다
print("AA → BB :", receive(1, "AA", "BB"))       # 이제 BB 도 안다
print("표:", mac_table)
```

### 정답 ⭐5-6

```python
import ipaddress

devices = {
    "PC0": {"vlan": 10, "ip": "192.168.10.10/26", "gateway": "192.168.10.1"},
    "PC1": {"vlan": 10, "ip": "192.168.10.20/26", "gateway": "192.168.10.1"},
    "PC2": {"vlan": 20, "ip": "192.168.10.70/26", "gateway": "192.168.10.65"},
}
checks = [("PC0", "PC1", True), ("PC0", "PC2", True), ("PC0", "PC2", False)]   # (출발, 도착, 라우터 있음)
# 1. checks 를 하나씩 꺼내 판정하고 「PC0 -> PC1 스위치 직접 전달」 꼴로 출력하세요
for src, dst, has_router in checks:               # 검사를 하나씩
    a = devices[src]                              # 출발 장비
    b = devices[dst]                              # 도착 장비
    same_net = ipaddress.ip_network(a["ip"], strict=False) == ipaddress.ip_network(b["ip"], strict=False)
    if a["vlan"] == b["vlan"] and same_net:       # VLAN 도 망도 같으면
        print(f"{src} -> {dst} 스위치 직접 전달")
    elif has_router:                              # 다르지만 라우터가 있으면
        print(f"{src} -> {dst} 게이트웨이 {a['gateway']}로 전달")
    else:                                         # 다르고 라우터도 없으면
        print(f"{src} -> {dst} 통신 불가")
```

```python
port_vlan = {1: 10, 2: 10, 3: 20, 4: 20, 5: 10}   # 포트 → VLAN 번호


def flood_ports(in_port):                         # in_port 로 들어온 브로드캐스트가 퍼질 포트들
    vlan = port_vlan[in_port]                     # 들어온 포트의 VLAN
    out = []
    for port in port_vlan:                        # 포트를 하나씩
        # 1. port 의 VLAN 이 vlan 과 같고 port 가 in_port 가 아니면 out 에 더하세요
        if port_vlan[port] == vlan and port != in_port:   # 같은 VLAN 이고 들어온 포트가 아니면
            out.append(port)
    return out


print("1번에서:", flood_ports(1))
print("3번에서:", flood_ports(3))
```

### 정답 6-5

```python
import ipaddress

routes = [                                        # (목적지 망, 다음 홉)
    ("0.0.0.0/0", "인터넷 게이트웨이"),
    ("192.168.10.0/26", "직접 연결 G0/0"),        # G0/0 · G0/1 은 라우터의 포트 이름
    ("192.168.10.64/26", "직접 연결 G0/1"),
]


def lookup(dest):                                 # 목적지 주소의 다음 홉을 돌려준다
    dest = ipaddress.ip_address(dest)
    best = None                                   # 지금까지 고른 줄
    for cidr, hop in routes:                      # 표를 한 줄씩
        net = ipaddress.ip_network(cidr)
        # 1. dest 가 net 안에 있고, best 가 None 이거나 net.prefixlen 이 best 의 prefixlen 보다 크면 best 에 (net, hop) 을 담으세요
        if dest in net and (best is None or net.prefixlen > best[0].prefixlen):   # 맞고 더 좁으면
            best = (net, hop)
    return best[1]                                # 고른 줄의 다음 홉


for d in ["192.168.10.20", "192.168.10.70", "8.8.8.8"]:
    print(d, "→", lookup(d))
```

```python
import ipaddress

vlan_subnet = {                                   # VLAN 번호 → 서브넷
    10: "192.168.10.0/26",
    20: "192.168.10.0/26",
    30: "192.168.10.64/27",
}
# 1. VLAN 을 둘씩 짝지어(10-20, 10-30, 20-30) 서브넷이 겹치면 「VLAN 10 과 20 이 같은 주소를 씀 — 라우터가 있어도 통신 안 됨」 을 출력하세요
for a, b in [(10, 20), (10, 30), (20, 30)]:       # 짝을 하나씩
    net_a = ipaddress.ip_network(vlan_subnet[a])
    net_b = ipaddress.ip_network(vlan_subnet[b])
    if net_a.overlaps(net_b):                     # 주소가 겹치면
        print(f"VLAN {a} 과 {b} 이 같은 주소를 씀 — 라우터가 있어도 통신 안 됨")
```

```python
import ipaddress

plan = [                                          # (부서, CIDR, VLAN)
    ("개발팀", "10.20.0.0/26", 10),
    ("운영팀", "10.20.0.64/27", 20),
    ("보안팀", "10.20.0.96/28", 30),

for name, cidr, vlan in plan:                     # 부서를 하나씩
    net = ipaddress.ip_network(cidr)              # 그 부서의 망
    # 1. gateway 에 net.network_address + 1 을 담으세요
    gateway = net.network_address + 1             # 첫 호스트를 게이트웨이로
    # 2. first 에 gateway + 1, last 에 net.broadcast_address - 1 을 담으세요
    first = gateway + 1                           # PC 에 줄 첫 주소
    last = net.broadcast_address - 1              # PC 에 줄 마지막 주소
    print(f"| {name} | {vlan} | {cidr} | {gateway} | {first} ~ {last} |")
```

### 정답 7-3

```python
import ipaddress

used = [                                          # 이미 쓰는 세 부서의 망
    ipaddress.ip_network("10.20.0.0/26"),
    ipaddress.ip_network("10.20.0.64/27"),
    ipaddress.ip_network("10.20.0.96/28"),
]
parent = ipaddress.ip_network("10.20.0.0/24")

server = None
for candidate in parent.subnets(new_prefix=28):   # /28 후보를 앞에서부터
    # 1. candidate 가 used 의 어느 것과도 겹치지 않으면 server 에 담고 반복을 끝내세요(break)
    hits = 0                                      # 겹치는 부서 수
    for net in used:
        if candidate.overlaps(net):
            hits = hits + 1
    if hits == 0:                                 # 아무와도 안 겹치면
        server = candidate
        break                                     # 처음 빈 자리를 찾았으니 끝

print("서버망:", server)
overlap = False
for net in used:                                  # 기존 부서와 하나씩 비교
    # 2. server 가 net 과 겹치면 overlap 을 True 로 바꾸세요
    if server.overlaps(net):
        overlap = True
print("겹침 있음:", overlap)
```
