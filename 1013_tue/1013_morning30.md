# 아침 과제 9 · 파일 옮기고 복사하기 — `mv` · `cp`

10월 13일 (화) · 아침 과제

**오늘 하는 일:** 10/7 에 마우스로 한 일 — 폴더 이름 바꾸기 · 파일 복사 — 을 **명령어로** 다시 해 봅니다.

오늘 새로 쓰는 명령은 `mv` · `cp` 두 개입니다. 연습은 **보관용 폴더 `security-agent-toolkit_old`** 안에서 합니다. 저장소 폴더가 아니라서 실수해도 괜찮습니다.

**오늘 못 끝냈으면 오후 5시 이후에 마무리합니다.**

---

## 1. 왜 이걸 하는지 찾아봅니다

| 질문 | 검색어 예시 |
|---|---|
| 서버에는 마우스가 없습니다. 보안 담당자는 서버에서 로그 파일을 어떻게 옮기고 백업할까요? | `리눅스 파일 복사`, `리눅스 mv cp 차이` |

정답을 맞히는 과제가 아닙니다. **찾은 내용을 자기 말로 적는 것**이 과제입니다.

---

## 2. 연습할 폴더로 갑니다

1. VS Code 에서 저장소 폴더 `security-agent-toolkit` 을 엽니다.
2. 왼쪽 목록의 빈 곳을 오른쪽 클릭 › **Open in Integrated Terminal** 을 누릅니다.
3. 한 칸 위로 올라가 보관용 폴더로 들어갑니다. **Tab** 키를 써 봅니다 — `security-agent-toolkit_` 까지 치고 Tab 을 누르면 나머지가 채워집니다.

```
$ cd ..
$ cd security-agent-toolkit_old
$ mkdir practice
$ cd practice
$ pwd
```

결과가 `…/security-agent-toolkit_old/practice` 로 끝나면 됩니다.

연습용 파일을 하나 만듭니다.

```
$ echo "2026-10-13 09:12:00 WARN failed login for admin" > a.log
$ ls
```

## 3. 여섯 가지를 해 봅니다

**명령 이름만 알려 드립니다. 옵션은 직접 찾습니다.** 할 때마다 `ls` 로 결과를 봅니다.

| # | 하고 싶은 일 | 쓰는 명령 | 나오면 성공 |
|---|---|---|---|
| ① | `a.log` 를 복사해 `b.log` 를 만든다 | `cp` | `a.log` · `b.log` 둘 다 보인다 |
| ② | `b.log` 의 이름을 `c.log` 로 바꾼다 | `mv` | `b.log` 는 없고 `c.log` 가 보인다 |
| ③ | `backup` 폴더를 만들고 `c.log` 를 그 안으로 옮긴다 | `mkdir` · `mv` | `ls backup` 에 `c.log` 가 보인다 |
| ④ | `backup` 폴더를 통째로 복사해 `backup2` 를 만든다 | `cp` + 옵션 하나 | `backup2` 안에도 `c.log` 가 있다 |
| ⑤ | `a.log` 를 `backup` 안으로 복사하는데, **같은 이름이 있으면 묻게** 한다 | `cp` + 옵션 하나 | 두 번째 실행 때 「덮어쓸까요?」라고 묻는다 |
| ⑥ | `cat` 으로 `backup/a.log` 의 내용을 본다 | `cat` | 로그 한 줄이 보인다 |

- ②와 ③을 비교해 보세요. **`mv` 는 같은 명령으로 「이름 바꾸기」와 「옮기기」를 다 합니다.** 뒤에 적은 것이 파일 이름이면 이름이 바뀌고, 폴더면 그 안으로 옮겨집니다.
- ④ 폴더는 그냥 `cp` 로는 복사되지 않습니다. 「폴더 안까지 모두」를 뜻하는 옵션을 찾습니다.
- ⑤ `cp` 와 `mv` 는 같은 이름이 있으면 **묻지 않고 덮어씁니다.** 증거 로그를 덮어쓰는 사고를 막으려면 묻게 하는 옵션을 붙이는 습관이 좋습니다. ⑤를 두 번 실행해서 확인합니다.

「cp 폴더 복사 옵션」, 「cp 덮어쓰기 확인 옵션」처럼 검색하면 나옵니다.
