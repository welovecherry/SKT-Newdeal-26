# 아침 과제 9 · 로그에서 필요한 줄만 골라내기

10월 13일 (화) · 아침 과제

**오늘 하는 일:** 로그 파일을 하나 만들고, 그 안에서 **필요한 줄만 골라내는 명령**을 익힙니다.

오늘 새로 쓰는 명령은 `cat` 과 `grep` 두 개입니다. `grep` 에 자주 쓰는 옵션 두 개를 붙여 봅니다.

**오늘 못 끝냈으면 오후 5시 이후에 마무리합니다.**

10/2 3교시에 눈으로만 보고 지나간 `cat` · `grep` 을 오늘 직접 칩니다.

---

## 1. 왜 이걸 배우는지 찾아봅니다

**왜 중요한가** — 쓰임새를 먼저 알아 두면 4번에서 옵션을 찾을 때 무엇을 골라내려는 것인지 분명해집니다.

먼저 **왜 필요한지**를 직접 찾아보고 한두 줄로 적습니다.

| 질문 | 검색어 예시 |
|---|---|
| 보안 담당자는 서버에서 왜 `grep` 을 쓸까요? | `grep 이란`, `리눅스 로그 검색 grep`, `서버 로그 확인 방법` |

정답을 맞히는 과제가 아닙니다. **찾은 내용을 자기 말로 적는 것**이 과제입니다.

---

## 2. `grep` 과 옵션의 뜻을 알아봅니다

**왜 중요한가** — `grep` 은 찾고 싶은 말이 든 줄만 보여 줍니다. 옵션을 붙이면 줄 번호를 보거나, 일치한 줄의 개수를 셀 수 있습니다.

`grep` 은 파일 안에서 원하는 글자가 든 줄을 찾는 명령입니다. **옵션**은 명령에 덧붙여 결과를 바꾸는 짧은 표시입니다.

기본 검색은 `grep "찾을 말" 파일이름` 모양입니다. 옵션을 쓸 때는 `grep` 바로 뒤에 붙입니다. 아래 예시에서 같은 검색어를 넣어도 옵션에 따라 결과가 달라지는 것을 봅니다.

아래 명령과 결과는 **모양을 먼저 읽어 보는 예시**입니다. 실제 입력은 `sample.log` 를 만든 뒤 4번에서 합니다.

| 명령 | 화면에 나오는 것 | 언제 쓰나 |
|---|---|---|
| `grep "끊김" sample.log` | `끊김`이 든 줄 | 해당 기록의 내용을 읽을 때 |
| `grep -n "끊김" sample.log` | 줄 번호와 해당 줄 | 파일에서 그 기록이 몇 번째 줄인지 찾을 때 |
| `grep -c "실패" sample.log` | 조건에 맞는 줄의 개수만 숫자로 | 같은 일이 몇 줄에서 일어났는지 셀 때 |

`-c` 는 글자가 나온 횟수가 아니라 **일치한 줄 수**를 셉니다. 한 줄에 `실패`가 여러 번 있어도 그 줄은 한 줄로 셉니다.
`-n`의 `n`은 number(번호), `-c`의 `c`는 count(개수)의 첫 글자입니다.

```text
$ grep -n "끊김" sample.log
4:09:12 와이파이 끊김

$ grep -c "실패" sample.log
2
```

첫 결과의 `4:`는 `끊김`이 파일의 4번째 줄에 있다는 뜻입니다. 둘째 결과의 `2`는 `실패`가 든 줄이 두 줄이라는 뜻입니다.

## 3. 오늘 쓸 로그 파일을 만듭니다

**왜 중요한가** — 짧은 로그로 먼저 연습하면 어떤 줄이 검색되는지 눈으로 확인하기 쉽습니다. 터미널 위치가 다르면 `grep` 이 파일을 찾지 못합니다.

어제 아침에 만든 **`network_zt`** 폴더에 로그 파일을 하나 만듭니다.

**① `network_zt` 안에 `sample.log` 를 만듭니다**

1. `network_zt` 폴더를 오른쪽 클릭하고 **New File**(새 파일)을 누릅니다.
2. 이름을 `sample.log` 로 적습니다.
3. 아래 여섯 줄을 그대로 복사해 붙여 넣습니다.

```
09:00 로그인 성공
09:03 로그인 실패
09:10 와이파이 연결
09:12 와이파이 끊김
09:20 로그인 실패
09:25 인터넷 연결
```

**② 터미널을 그 폴더에서 엽니다**

`network_zt` 폴더를 오른쪽 클릭하고 **Open in Integrated Terminal**(통합 터미널에서 열기)을 누릅니다.

```
$ pwd
$ ls
```

- `pwd` 의 결과가 `…/security-agent-toolkit/network_zt` 로 끝나면 됩니다. 앞부분은 사람마다 다릅니다.
- `ls` 의 목록에 `sample.log` 가 보이면 됩니다.

## 4. 필요한 줄을 찾고 옵션을 붙여 봅니다

**왜 중요한가** — 관제에서는 긴 로그에서 필요한 줄을 찾고, 위치와 개수를 확인합니다. 아래 예시로 기본 검색과 자주 쓰는 옵션 두 개를 익힙니다.

먼저 파일 전체를 봅니다.

```bash
cat sample.log
```

여섯 줄이 모두 보이면 파일을 읽은 것입니다.

이제 `grep` 으로 원하는 줄을 찾아봅니다.

| # | 하고 싶은 일 | 입력할 명령 | 나오면 성공 |
|---|---|---|---|
| ① | 로그인 실패 줄을 찾는다 | `grep "실패" sample.log` | 로그인 실패 두 줄이 보인다 |
| ② | 와이파이가 끊긴 줄과 줄 번호를 찾는다 | `grep -n "끊김" sample.log` | `4:`로 시작하는 줄이 보인다 |
| ③ | 로그인 실패가 든 줄이 몇 개인지 센다 | `grep -c "실패" sample.log` | `2`만 보인다 |

①은 `grep` 의 기본 검색입니다. ②에서 `-n` 은 줄 번호를 붙이고, ③에서 `-c` 는 조건에 맞는 줄 수를 셉니다.
