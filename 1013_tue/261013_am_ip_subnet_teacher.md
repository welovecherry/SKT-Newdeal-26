# <mark style="display:block; background:#c8e6c9; color:#1a1a1a; padding:6px 12px; border-radius:4px">2교시 (10:00–10:50) · IP 주소를 펼치기 · 사설 IP 와 공인 IP</mark>

### 왜 필요한가

1. 관제 로그의 첫 칸은 거의 언제나 IP 주소입니다. 그 주소가 **우리 회사 안**인지 **바깥**인지부터 가려야 합니다.
2. 그 기준이 **사설 IP**(회사 · 집 안에서만 쓰는 주소)와 **공인 IP**(인터넷 전체에서 하나뿐인 주소)입니다.
3. 안의 주소는 밖으로 나갈 때 **NAT**(냇 · 주소 바꾸기)로 공인 주소로 바뀝니다. 그래서 로그에 찍힌 주소가 실제 PC 의 주소와 다를 수 있습니다.

### 2.1 IP 주소는 0과 1 서른두 칸

`192.168.10.25` 는 사람이 읽는 모양입니다. 컴퓨터는 점으로 나뉜 **마디 네 개**를 각각 **0과 1 여덟 칸**(8비트)으로 읽습니다. 그래서 IPv4(아이피 브이포) 주소는 모두 **32비트**(비트 · 0 또는 1 한 칸)입니다.

| 마디 | 10진수(평소 쓰는 수) | 2진수(0과 1 로만 쓰는 수 · 8칸) |
|---|---|---|
| 1 | 192 | `11000000` |
| 2 | 168 | `10101000` |
| 3 | 10 | `00001010` |
| 4 | 25 | `00011001` |

여덟 칸이 전부 1 이면 `11111111` = 255 입니다. 그래서 한 마디에는 **0~255** 만 들어갑니다(256가지).

#### 🐍 문법 상자 · `format(숫자, "08b")` — 2진수 여덟 칸으로

```python
print(format(5, "08b"))
print(format(255, "08b"))
print(len(format(25, "08b")))
# 00000101
# 11111111
# 8
```

| 쓰는 것 | 뜻 |
|---|---|
| `b` | 2진수(binary)로 바꾼다 |
| `08` | 빈 앞자리를 0 으로 채워 **여덟 칸**을 만든다 |
| `int("25")` | 글자 `"25"` 를 숫자 25 로 (1과목) |

⚠ `"08b"` 를 따옴표 없이 `08b` 로 쓰면 `SyntaxError` 입니다. 글자로 넘겨야 합니다.

### 2.2 사설 IP 와 공인 IP

| 사설 IP 범위 | 예 | 주의 |
|---|---|---|
| `10.0.0.0` ~ `10.255.255.255` | `10.0.0.8` | 첫 마디가 10 이면 전부 |
| `172.16.0.0` ~ `172.31.255.255` | `172.20.5.6` | ⚠ **둘째 마디가 16~31 일 때만.** `172.32.5.6` 은 공인 |
| `192.168.0.0` ~ `192.168.255.255` | `192.168.10.25` | 첫 두 마디가 192.168 |

- 세 범위는 인터넷 공통 약속입니다. 이 범위 밖은 **공인 IP** 입니다.
- 사설 IP 는 회사마다 겹쳐도 됩니다. 인터넷으로는 나가지 않기 때문입니다.
- **사설이면 안전, 공인이면 공격이라는 뜻은 아닙니다.** 안 · 밖을 가르는 첫 기준일 뿐입니다.

### 2.3 NAT — 안의 주소를 밖의 주소로

공유기는 안의 PC 가 인터넷으로 나갈 때 **출발지 주소를 자기 공인 IP 로 바꿔** 보냅니다. 이것이 NAT(Network Address Translation)입니다.

> 학생 문서에서는 아래 표의 일부 칸이 **[찾아 쓰기]** 로 비어 있습니다. 강사용에는 채운 표를 둡니다.

| 방식 | 바꾸는 법 |
|---|---|
| 정적 NAT | 안의 주소 하나 ↔ 공인 주소 하나를 **고정**해 둔다 |
| 동적 NAT | 공인 주소 여러 개 중 빈 것을 **그때그때** 하나 준다 |
| **PAT**(팻 · Port Address Translation) | 공인 IP **하나**를 여러 PC 가 같이 쓰고, **포트 번호로** 누구 것인지 구별한다 — 집 · 학원 공유기가 대부분 이것 |

PAT 공유기는 「바깥 포트 40002번 = 안의 `192.168.10.25:51234`」 같은 **변환표**를 가지고 있다가, 답이 오면 표를 보고 원래 PC 로 돌려줍니다.

**관제에서는** — 마스크 · 망 경계 계산이 모두 이 여덟 칸 단위로 이루어지므로, 2진수로 펼칠 줄 알아야 경계를 검산할 수 있습니다.

**강사 메모** — 칠판에 자리값 `128 64 32 16 8 4 2 1` 을 적고 192 와 10 을 함께 맞춰 봅니다. 「왜 꼭 여덟 칸인가요?」에는 「한 마디가 0~255 이고 255 가 1 여덟 개라서」라고 답합니다. 끝나면 「168 은?」을 물어 `10101000` 이 나오는지 확인합니다.

```python
def to_bits(ip):                                  # IP 주소를 2진수 32칸 글자로 바꾸는 함수
```

**관제에서는** — 주소를 32칸으로 펼쳐 봐야 마스크가 어디서 망과 장비를 가르는지 확인할 수 있습니다.

### ✍️ 문제 2-3 · 사설 IP 판별기 (`private_ip.py`)

<b style="color:#1e88e5">어디서</b> — VS Code 에서 `private_ip.py` 만들기 → 터미널에서 `python private_ip.py` 실행

주소가 사설 IP 인지 판별하는 `is_private` 를 완성하시오. **172 의 함정**에 걸리지 않아야 합니다.

#### 🐍 문법 상자 · `and` · `or` · 범위 비교

```python
second = 20
print(16 <= second <= 31)          # True — 16 이상 31 이하
print(second == 10 or second == 20)
# True
# True
```

| 쓰는 것 | 뜻 |
|---|---|
| `16 <= second <= 31` | 둘 사이에 있나 (양 끝 포함) |
| `A and B` | 둘 다 참이어야 참 |
| `A or B` | 하나만 참이어도 참 |

⚠ `first == 172` 만 보면 `172.32.5.6` 까지 사설로 잘못 판정합니다. 둘째 마디도 봐야 합니다.

```python
def is_private(ip):                               # 사설 IP 면 True 를 돌려주는 함수
    parts = ip.split(".")                         # 점으로 나눈 마디 네 개
    first = int(parts[0])                         # 첫 마디(숫자)
    second = int(parts[1])                        # 둘째 마디(숫자)
    # 1. first 가 10 이면 True 를 return 하세요
```

### 왜 필요한가

1. 같은 `192.168.10` 으로 시작해도 관리자가 경계를 어디에 뒀는지에 따라 **다른 망**일 수 있습니다.
2. 같은 망이면 스위치(같은 망 안의 장비들을 잇는 장비)가 바로 전달하고, 다른 망이면 **게이트웨이(라우터 · 망과 망을 잇는 장비)** 를 거칩니다. 방화벽(허용 · 차단 규칙으로 통신을 거르는 장비) 규칙도 이 경계로 씁니다.
3. 그 경계를 정하는 값이 `255.255.255.0` — **서브넷 마스크**(서브넷 · 큰 망을 나눈 작은 망)입니다.

### 3.1 서브넷 마스크와 CIDR

| | 1 인 칸 | 0 인 칸 |
|---|---|---|
| 서브넷 마스크 32칸 | **네트워크 부분** — 같은 망이면 모두 같다 | **호스트 부분**(호스트 · 망 안의 장비 하나) — 장비마다 다르다 |

| 서브넷 마스크 | 2진수의 마지막 마디 | CIDR(사이더 · 1 의 개수로 쓰는 표기) | 주소 수 | 장비에 쓸 수 있는 수 |
|---|---|---|---|---|
| `255.255.255.0` | `00000000` | `/24` | 256 | 254 |
| `255.255.255.128` | `10000000` | `/25` | 128 | 126 |
| `255.255.255.192` | `11000000` | `/26` | 64 | 62 |
| `255.255.255.224` | `11100000` | `/27` | 32 | 30 |
| `255.255.255.240` | `11110000` | `/28` | 16 | 14 |

- CIDR 숫자가 1 커지면 주소 수는 **절반**이 됩니다.
- 쓸 수 있는 수가 2 적은 이유: **첫 주소**는 망 자체를 가리키는 **네트워크 주소**, **마지막 주소**는 망 전체에 한 번에 보내는 **브로드캐스트(broadcast) 주소**라 장비에 주지 않습니다.
- 기본 게이트웨이도 그 사이의 주소 하나를 씁니다(보통 첫 번째).

#### 🐍 문법 상자 · `ipaddress` 로 망 계산하기

```python
import ipaddress
net = ipaddress.ip_network("192.168.10.70/26", strict=False)
print(net)
print(net.network_address, net.broadcast_address, net.num_addresses)
# 192.168.10.64/26
# 192.168.10.64 192.168.10.127 64
```

| 쓰는 것 | 뜻 |
|---|---|
| `ipaddress.ip_network("주소/CIDR", strict=False)` | 그 주소가 속한 **망**을 만든다. `strict=False` 는 「망의 첫 주소가 아니어도 받아 준다」 |
| `.network_address` | 네트워크 주소(첫 주소) |
| `.broadcast_address` | 브로드캐스트 주소(마지막 주소) |
| `.num_addresses` | 주소 수 — 쓸 수 있는 수는 여기서 2 를 뺀다 |
| `.netmask` | 서브넷 마스크 |

⚠ `strict=False` 를 빼면 `192.168.10.70/26` 처럼 망의 첫 주소가 아닌 값에서 `ValueError`(값이 맞지 않다는 에러)가 납니다.

#### 정답

**결과** — `26` · `6`

**왜** — 1 이 26개라 `/26` 이고, 호스트 자리 6칸이라 주소는 2⁶ = 64개, 장비에 쓸 수 있는 수는 64 − 2 = 62 입니다.

**자주 틀리는 곳** — 0 의 개수 6 을 주소 수로 읽는 것입니다. 6 은 칸 수이고 주소 수는 2 를 여섯 번 곱한 64 입니다.

**관제에서는** — 로그 · 방화벽 규칙의 `/26` 을 보고 그 규칙이 주소 몇 개를 덮는지 바로 셀 수 있어야 합니다.

**강사 메모** — 「0 의 개수 = 칸 수, 주소 수 = 2 를 그만큼 곱한 수」를 분명히 나눠 말합니다. 「`/24` 는요?」에는 「0 이 8칸이라 256개, 쓸 수 있는 수는 254」라고 답합니다. 이어서 학원망 `/16` 은 0 이 16칸이라 주소가 2¹⁶ = 65536개라고 미리 알려 두면 3-2 에서 덜 헷갈립니다.

# <mark style="display:block; background:#c8e6c9; color:#1a1a1a; padding:6px 12px; border-radius:4px">4교시 (12:00–12:50) · 서브네팅 — 부서마다 필요한 만큼 나누기</mark>

### 왜 필요한가

1. 회사가 `192.168.50.0/24`(주소 256개)를 받았습니다. 개발팀 · 운영팀 · 보안팀을 **다른 망**으로 나눠야 서로의 PC 에 함부로 닿지 않습니다.
2. 큰 망을 작은 망 여러 개로 나누는 일이 **서브네팅**입니다.
3. 아무렇게나 나누면 주소가 모자라거나 **두 부서가 같은 주소를 받는** 사고가 납니다. 그래서 계산하고 검증합니다.

### 4.1 장비 수 → CIDR

| 필요한 장비 수 | 호스트 칸 | 쓸 수 있는 수 | CIDR |
|---|---|---|---|
| 10대 | 4칸 | 2⁴ − 2 = 14 | `/28` |
| 25대 | 5칸 | 2⁵ − 2 = 30 | `/27` |
| 50대 | 6칸 | 2⁶ − 2 = 62 | `/26` |

**처음으로 「충분」해지는 가장 작은 크기**를 고릅니다. 더 크게 주면 다른 부서 몫이 줄어듭니다.

### 4.2 두 가지 나누는 법

| | FLSM(에프엘에스엠 · Fixed Length Subnet Mask) | VLSM(브이엘에스엠 · Variable Length Subnet Mask) |
|---|---|---|
| 뜻 | **모든** 부서에 같은 크기 | 부서마다 **필요한 크기** |
| 예 (50 · 25 · 10대) | `/26` 네 개 — 전부 62칸씩 | `/26` · `/27` · `/28` |
| 장점 | 단순하다 | 주소를 아낀다 |
| 단점 | 작은 부서에 빈 주소가 많이 남는다 | 계산 · 검증이 필요하다 |

**VLSM 은 큰 블록부터 놓습니다.** `/26` 은 0 · 64 · 128 · 192 에서만 시작할 수 있어서, 작은 것을 먼저 흩어 놓으면 큰 블록이 들어갈 자리가 없어집니다.

```
192.168.50.0/24
  0 ─────────── 63 │ 64 ──── 95 │ 96 ─ 111 │ 112 ───────────────── 255
  개발팀 /26 (62대) │ 운영팀 /27  │ 보안팀 /28 │ 남는 공간 (다음 부서용)
```

#### 🐍 문법 상자 · `**` 거듭제곱 · `.subnets()` · `.overlaps()`

```python
import ipaddress
print(2 ** 6 - 2)
parent = ipaddress.ip_network("192.168.50.0/24")
print(len(list(parent.subnets(new_prefix=26))))
a = ipaddress.ip_network("192.168.50.0/26")
b = ipaddress.ip_network("192.168.50.32/27")
print(a.overlaps(b))
# 62
# 4
# True
```

| 쓰는 것 | 뜻 |
|---|---|
| `2 ** 6` | 2 를 여섯 번 곱한다(64) |
| `망.subnets(new_prefix=26)` | 그 망을 `/26` 크기로 나눈 작은 망들 |
| `망.overlaps(다른 망)` | 주소가 **하나라도 겹치면** `True` |

⚠ `subnets()` 의 결과는 리스트가 아니라 차례로 꺼내는 것이라 개수를 세려면 `list()` 로 감쌉니다.

**왜** — 첫 호스트는 네트워크 주소 + 1, 마지막 호스트는 브로드캐스트 주소 − 1 입니다. 운영팀 `/27` 은 64~95 라 65~94 를 씁니다.

**자주 틀리는 곳** — 마지막 호스트에 브로드캐스트 주소(`10.20.0.63` · `.95` · `.111`)를 그대로 적는 것입니다.

**관제에서는** — 이 표가 있으면 경보에 찍힌 `10.20.0.○○` 가 어느 부서 장비인지 표만 보고 찾습니다.

**강사 메모** — 주소 객체에 `+ 1` · `- 1` 을 그대로 할 수 있다는 점을 짚습니다. 「글자 주소에 1 을 더해도 되나요?」에는 「글자는 안 되고 `ip_network()` 로 만든 망의 주소라서 됩니다」라고 답합니다. 출력을 `day02_subnet_design.md` 2절에 붙인 뒤 `Ctrl + Shift + V` 미리보기에서 표로 보이는지 학생 화면에서 확인합니다.

### 4교시 한눈에

| 하려는 일 | 쓰는 것 |
|---|---|
| 장비 수 → CIDR | 처음으로 `2 ** 칸 - 2 >= 필요` 인 칸 |
| 같은 크기로 나누기 | `망.subnets(new_prefix=26)` |
| 주소가 속한 블록 | `ip_network(f"{주소}/27", strict=False)` |
| 설계 검증 | 용량 `>=` · 겹침 `.overlaps()` |
