# 깃배시 — 명령어로 폴더를 확인합니다

9월 28일 (월) · 아침 30분 · 09:20~09:50

**오늘 하는 일:** 왜 이걸 배우는지 스스로 찾아 정리하고, 깃배시를 설치해서 명령 세 개를 실행합니다.

명령어를 외우지 않아도 됩니다. 순서대로 하다가 시간이 끝나면 **거기까지가 오늘 몫입니다.** 못 끝낸 부분은 내일 아침에 이어서 합니다.

---

## 1. 왜 이걸 배우는지 찾아봅니다 (7분)

앞으로 여러 날에 걸쳐 리눅스 명령어와 깃허브를 조금씩 배웁니다. 먼저 **왜 필요한지**를 직접 찾아보고 각각 한두 줄로 적습니다.

| 질문 | 검색어 예시 |
|---|---|
| 보안 담당자는 왜 리눅스 명령어를 쓸까요? | `보안관제 리눅스 명령어 이유`, `서버는 왜 리눅스` |
| 개발자와 보안 담당자는 왜 깃허브에 코드를 올릴까요? | `깃허브란`, `github 왜 쓰나`, `버전관리 필요성` |

정답을 맞히는 과제가 아닙니다. **찾은 내용을 자기 말로 적는 것**이 과제입니다.

---

## 2. 이 말들이 무슨 뜻인지 찾아봅니다 (5분)

검색해서 읽고 자기 말로 한 줄씩 적습니다. 틀려도 됩니다.

| 찾아볼 말 | 이런 내용이 나옵니다 |
|---|---|
| 터미널 | 명령어를 글자로 입력해 실행하는 프로그램 |
| 경로 (path) | 파일이나 폴더가 어느 위치에 있는지 나타낸 주소 |
| 깃배시 (Git Bash) | 윈도우에서 리눅스·맥과 같은 명령어를 쓸 수 있게 하는 터미널 |

---

## 3. 깃배시를 찾아서 설치합니다 (10분)

설치 파일을 어디서 받는지도 직접 찾습니다. `git bash 설치` 또는 `git for windows download` 로 검색합니다.

- 받는 파일 이름은 `Git-2.51.0-64-bit.exe` 처럼 생겼습니다. 숫자는 다를 수 있습니다.
- 설치 화면이 여러 번 나옵니다. **두 군데만 바꾸고 나머지는 「Next」**를 누릅니다.
  1. `Choosing the default editor` — **Notepad** 를 선택합니다
  2. `Adjusting the name of the initial branch` — **main** 을 선택합니다
- 마지막에 Install 을 누릅니다.

여러 사람이 같이 받으면 느려질 수 있습니다. 다운로드가 오래 걸리면 기다리는 동안 1번과 2번을 마무리합니다.

---

## 4. 깃배시를 실행합니다

윈도우 시작 버튼을 누르고 **`git bash`** 를 입력한 뒤, 검색 결과를 클릭합니다.

창이 열리고 마지막 줄에 **`$`** 가 표시되면 정상입니다. 명령어는 `$` 뒤에 입력합니다.

---

## 5. 명령 세 개를 실행합니다 (8분)

한 줄을 입력하고 **엔터**를 누릅니다. 아래는 강사 PC 의 출력이고, 각자 화면에는 계정 이름이 다르게 나옵니다.

### ① 지금 위치한 폴더의 경로를 출력합니다

```
$ pwd
/c/Users/hong
```

### ② 그 폴더 안의 목록을 출력합니다

```
$ ls
Desktop  Documents  Downloads  Music  Pictures  Videos
```

### ③ 이름이 점으로 시작하는 항목까지 함께 출력합니다

```
$ ls -a
.  ..  .bash_history  .gitconfig  Desktop  Documents  Downloads
```

---

## 6. 확인합니다

- [ ] 1번 질문 두 개에 답을 적었습니다
- [ ] 창에 `$` 가 표시됩니다
- [ ] `pwd` 의 출력이 `/c/Users/` 로 시작합니다
- [ ] `ls` 의 출력에 `Desktop` 이 있습니다
- [ ] `ls -a` 의 출력에는 점(`.`)으로 시작하는 항목이 더 있습니다

안 되면 **어디서 멈췄는지만 적어 둡니다.** 내일 아침에 같이 봅니다.

---

## ⭐ 다 한 사람만 합니다

`pwd` 가 출력한 경로를 적어 두고, 윈도우 탐색기 주소창의 경로와 **표기가 어떻게 다른지** 한 줄로 적습니다.
(힌트: `/` 와 `\`)
